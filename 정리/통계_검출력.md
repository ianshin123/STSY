## 설계

**대응표본 t-검정.** 같은 개체의 노출 전후를 비교한다.

이유: 축삭 지름이 개체마다 달라 절대 속도가 크게 다르다.
개체 내 비교로 그 변동을 통째로 상쇄한다 → [`전도속도_결정요인.md`](전도속도_결정요인.md).

- 유의수준 α = 0.05, 양측
- 검정력 1−β = 0.80
- 효과 크기는 **변화율(%)** 로 표현. SD도 같은 단위(반복 측정 변동의 %)

---

## SD_rep — 먼저 재야 하는 값

```
SD_rep = 같은 개체 · 같은 조건 · 반복 측정의 표준편차 (%)
```

**이 값을 모르면 실험 설계를 할 수 없다.** 단계 1의 유일한 목표다.
조건을 아무것도 바꾸지 않고 같은 개체를 10회 반복 측정해 구한다.

SD_rep에 들어오는 것들:
- 온도 변동 · 마취 깊이 변동 · 전극 접촉 상태
- 전극 간격 실측 오차 (d 1 mm = 4 %)
- 채널 간 고정 지연의 변동
- Δt 추정 알고리즘의 분산

**전자회로의 시간분해능은 여기 거의 기여하지 않는다** (192 kHz = 5.2 µs, 목표 25 µs).

### ★ 문헌의 변동 수치 — SD_rep ≤ 3 %는 야심찬 목표다

**어느 논문도 우리가 필요한 SD_rep(같은 개체 · 같은 조건 반복 측정의 SD)을 보고하지 않는다.**
비교 가능한 것은 아래 셋뿐이고, 전부 다른 종류의 변동이다.

| 출처 | 값 | 무슨 변동인가 |
|---|---|---|
| Bähring & Bauer 2014 Table 1 | 30.2 ± 0.7 m/s **(SE, n = 74 시행)**<br>→ **SD ≈ 6.0 m/s = 약 20 %**<br>실측 범위 **10.3 – 54.8 m/s** | **시행 간** — 학생·개체·세션이 전부 섞여 있다 |
| Shannon 등 2014 | MGF 22.8 ± 4.5 m/s **(SD)** = 약 20 % | **개체 간** (7마리, 개체당 5회) — 명시돼 있다 |
| Mazzia 등 2018 | 대조군 12.83 ± 0.53 m/s = 약 4.1 % | **개체 간** (용량당 8마리) |

**읽는 법:**
- **개체 간 변동(20 % · 4.1 %)은 우리 설계가 상쇄한다.** 개체 내 전후 비교이기 때문이다.
  Shannon의 ±4.5가 개체 간이라는 것이 확인되면서 열려 있던 위험 하나가 닫혔다.
- **Bähring의 약 20 %는 다르다.** 시행 간 변동이라 우리 SD_rep과 성격이 가장 가깝고,
  **우리 목표 3 %의 7배**다.
- 다만 그 20 %는 **의대생 74시행**에서 나온 값이다.
  10.3–54.8 m/s라는 5배 범위는 생물학적 변동이 아니라
  **조작·판독 오차가 지배한다고 보는 것이 타당하다**(우리 추론).
  화면에서 커서로 Δt를 읽는 학생 여럿 vs 상호상관으로 자동 추정하는 한 사람은 다르다.
- **그래도 3 %는 증명되지 않은 목표다.** 단계 1이 존재하는 이유가 정확히 이것이다.

**만약 SD_rep이 20 %로 나오면**: 3 % 검출에 필요한 개체가 수백 마리가 되어 실험이 불가능해진다.
그때는 목표 효과를 다시 잡거나(우리 조건에서 실제 효과가 3 %보다 클 수 있다 —
Mazzia는 25 %, Gooneratne도 큰 효과를 봤다) 측정을 근본적으로 개선해야 한다.
**단계 1을 건너뛰면 이 사실을 노출 실험이 다 끝난 뒤에 알게 된다.**

## 검출 가능 최소 변화율 (MDE)

비중심 t 분포로 정확히 계산한 값. 단위는 %.

| n | SD 1 % | SD 2 % | SD 3 % | SD 5 % |
|---|---|---|---|---|
| 5 | 1.68 % | 3.36 % | 5.05 % | 8.41 % |
| 10 | 1.00 % | 1.99 % | **2.99 %** | 4.98 % |
| 15 | 0.78 % | 1.56 % | 2.33 % | 3.89 % |
| 20 | 0.66 % | 1.32 % | 1.98 % | 3.30 % |
| 30 | 0.53 % | 1.06 % | 1.59 % | 2.65 % |

계수(MDE ÷ SD): n=5 → 1.6820, n=10 → 0.9960, n=15 → 0.7780, n=20 → 0.6604, n=30 → 0.5292.

## 3 % 검출에 필요한 최소 개체 수

| SD_rep | 필요 n | 그때 MDE |
|---|---|---|
| 1 % | 4 | 2.13 % |
| 2 % | 6 | 2.87 % |
| 3 % | **10** | **2.99 %** |
| 5 % | **24** | 2.99 % |

---

## 읽는 법

목표는 **3 % 변화 검출**이다 (사람 고노출군 감각신경의 보고값 →
[`중금속_신경독성.md`](중금속_신경독성.md)).

- SD_rep 3 %에 n = 10이면 MDE 2.99 % — **목표선에 여유 없이 딱 걸린다.**
  10마리는 최소선이지 안전선이 아니다. 15마리면 2.33 %로 여유가 생긴다.
- SD_rep 5 %면 n = 10으로 4.98 %까지밖에 못 잡아 **3 % 효과를 놓친다.**
  24마리 이상으로 늘리거나 측정 정밀도를 개선해야 한다.
- **SD_rep을 5 %에서 3 %로 줄이는 것이 개체를 24마리에서 10마리로 줄이는 것과 같다.**
  개체를 더 구하는 것보다 장치를 다듬는 쪽이 대개 싸다.

## 정규근사를 쓰면 안 되는 이유

MDE를 `(z₀.₉₇₅ + z₀.₈₀)/√n · SD = 2.8016/√n · SD` 로 계산하는 방식이 흔하다.
**이건 n이 클 때만 맞는 근사이고, 우리 n 범위에서는 검출 한계를 낙관적으로 내놓는다.**

| n | 정규근사 | 정확 (비중심 t) | 과소평가 |
|---|---|---|---|
| 5 | 1.2529 · SD | 1.6820 · SD | **25.5 %** |
| 10 | 0.8859 · SD | 0.9960 · SD | 11.1 % |
| 15 | 0.7234 · SD | 0.7780 · SD | 7.0 % |
| 20 | 0.6265 · SD | 0.6604 · SD | 5.1 % |
| 30 | 0.5115 · SD | 0.5292 · SD | 3.4 % |

두 가지가 빠져 있기 때문이다.
① 임계값이 z가 아니라 자유도 n−1의 t다 (더 크다)
② 표본 SD 자체가 확률변수라 검정통계량이 **비중심 t**를 따른다

원 설계 문서가 이 근사를 썼고 그 값이 이 저장소에 들어오기 전에 교체됐다.
경위는 [`../결정기록.md`](../결정기록.md) 「정정」.

## 검정 자체의 전제 — 확인해야 할 것들

이 표는 **차이값이 정규분포를 따른다**는 가정 위에 서 있다.
n = 10에서 정규성 검정은 힘이 없으므로, 실제로 할 일은:

- 단계 1의 반복 측정 10개로 **분포 모양을 눈으로 본다** (히스토그램 · Q-Q)
- 이상치가 나오면 그 시행의 [`메타.md`](../실험/) 기록(온도 · 접촉 상태)을 먼저 확인한다.
  **원인 없이 지우지 않는다**
- 분포가 심하게 치우치면 **Wilcoxon 부호순위 검정**을 예비로 둔다
  (검정력이 약 5 % 낮아지므로 n을 그만큼 늘려야 한다)

## 다중비교 — 단계 4에서 필요해진다

본 실험은 금속 2종 × 농도 4단계 × 시점 5개다.
전후 비교를 전부 개별 t-검정으로 돌리면 **검정 횟수가 수십 번**이 되어
α = 0.05가 무의미해진다.

**이 저장소에 아직 결정된 것이 없다.** 단계 3 결과가 나온 뒤 정한다.
후보: 선형혼합모형(개체를 임의효과로) · 반복측정 ANOVA · Holm 보정.
**단계 4 설계를 확정하기 전에 통계 방법을 먼저 정해야 한다** — 사후에 고르면 p-해킹이 된다.
