# 활동전위와 이온 통로

우리가 재려는 모든 것이 여기서 출발한다.
**중금속이 건드리는 것도, 우리가 측정하는 것도 결국 이온 통로다.**

---

## 활동전위가 만들어지는 순서

신경 세포는 쉬고 있을 때 막 안쪽이 바깥보다 약 **−70 mV**다.
자극이 들어와 이 전위가 역치를 넘으면 연쇄 반응이 시작된다.

1. **나트륨 통로가 열린다 — 약 1 ms**
   전압에 반응하는 Na⁺ 통로가 빠르게 열리고 나트륨이 세포 안으로 쏟아진다.
   막 안쪽이 순식간에 **+30 mV** 근처까지 뒤집힌다. 이것이 스파이크의 **상승기**다.
2. **나트륨 통로가 스스로 닫히고 칼륨 통로가 열린다**
   Na⁺ 통로에는 별도의 불활성화 장치가 있어 열린 직후 스스로 막힌다.
   동시에 느린 K⁺ 통로가 열려 칼륨이 빠져나가며 전위가 원래대로 돌아온다. **하강기**다.
3. **국소 전류가 옆칸을 흥분시킨다**
   한 지점이 양전위가 되면 그 전류가 축삭 안을 따라 흘러 인접 부위를 역치까지 밀어올린다.
   그러면 거기서 같은 일이 반복된다.
   **이 연쇄가 곧 '신호가 달린다'는 것의 실체다.**

이 1 ms짜리 짧은 파형이 우리 통과대역 하단을 300 Hz에 두는 이유다
(→ [`생체신호_증폭회로.md`](생체신호_증폭회로.md)).

## 호지킨–헉슬리 모델

호지킨과 헉슬리는 이 과정을 **통로의 열림 확률**로 수식화했다.
막을 지나는 전류는 이렇게 쓴다.

```
I = ḡNa · m³h · (V − ENa) + ḡK · n⁴ · (V − EK) + ḡL · (V − EL)
```

- **m** = 나트륨 통로 활성화
- **h** = 나트륨 통로 불활성화
- **n** = 칼륨 통로 활성화

셋 다 0과 1 사이의 값이고, 전압과 시간에 따라 변한다.

각 게이팅 변수는 전압에 의존하는 속도상수 α, β 로 다음을 따른다.

```
dx/dt = αx(V)·(1 − x) − βx(V)·x        (x = m, h, n)
```

V를 상수로 고정하면 α, β 도 상수가 되어 정확히 풀린다.

```
x(t) = x∞ + (x₀ − x∞)·e^(−t/τx),   x∞ = α/(α+β),   τx = 1/(α+β)
```

## 이 모델이 우리 실험의 이론적 기둥인 이유

> **중금속이 이온 통로를 방해한다면, 그것은 m · h · n 이 변하는 속도를 바꾼다는 뜻이다.**
> 통로가 더 느리게 열리면 옆칸을 역치까지 끌어올리는 데 시간이 더 걸리고,
> 그것이 그대로 **전도속도 저하**로 나타난다.

이 논리 사슬이 실험 전체를 떠받친다.
사슬의 다음 고리 — 무엇이 전도속도를 정하는가 — 는 [`전도속도_결정요인.md`](전도속도_결정요인.md)에,
중금속이 어느 지점을 때리는가는 [`중금속_신경독성.md`](중금속_신경독성.md)에 있다.

**주의**: "중금속 → m·h·n 지연 → 전도속도 저하"는 문헌이 지지하는 **가설**이지
지렁이에서 확인된 사실이 아니다. 확인하는 것이 이 연구의 목적이다.

## 신이안의 선행 작업과의 연결

동아리 멘토멘티 「호지킨–헉슬리 방정식의 근사」가 **정확히 이 식의 m · h · n 을
구간별로 풀어낸 작업**이다. 컴퓨터를 쓰지 않고, 호지킨이 전압고정법으로 V를 붙잡았던 것처럼
V를 구간마다 상수로 고정해 손으로 미분 가능한 닫힌 형태 V(t)를 세웠다.

접근: 구간 내 V 고정 → α, β 상수 → 게이팅 방정식이 위 지수 꼴로 정확히 풀린다 →
m³ · n⁴ 을 곱셈공식으로 전개 → dV/dt에 대입하면 서로 다른 지수항 11개 + 상수항 →
적분하면 구간별 닫힌 형태 V(t). 활동전위 전체를 상승기·정점·하강기·복귀기 4구간으로 나눈다.
가장 단순화하면 `V(t) ≈ E_L + A(e^(−t/τ₂) − e^(−t/τ₁))`.

FitzHugh-Nagumo · Morris-Lecar · Izhikevich가 변수를 4개에서 2개로 **줄여서** 위상평면 해석을
가능하게 하는 것과 **반대 방향**이다 — 변수 4개와 속도함수 6개, 모든 상수의 생리학적 의미를
그대로 둔 채 원래 모델의 해를 근사한다.

한계(본인 명시): 구간 안에서 α, β를 고정해 되먹임을 끊었으므로 재현되는 것은 **곡선의 모양이지
수치적 일치가 아니다.** 역치 아래 자극의 무발화, 연속 발화, 불응기는 담기지 않는다.

**그때 종이 위에서 다룬 변수를 이번에는 측정값으로 잡는다.**
