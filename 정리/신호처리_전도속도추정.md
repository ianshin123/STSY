# 신호처리 — Δt 추정과 전도속도

목표 정밀도가 **Δt 25.8 µs**다 (3 % 효과 = 25 mm 구간에서).
이 노트는 그 정밀도를 어떻게 얻는가를 다룬다.

---

## 기본 식

```
v [m/s] = d [mm] ÷ Δt [ms]
```

d = 두 기록 지점(전극 쌍의 중심) 사이 거리 · Δt = 두 채널의 시간차.
→ [`세포외기록_원리.md`](세포외기록_원리.md)

**오차 전파** — 두 상대오차의 제곱합의 제곱근이다(합이 아니다):

```
σv/v = √( (σd/d)² + (σΔt/Δt)² )
```

| 오차원 | d = 25 mm 에서 | v에 주는 상대오차 |
|---|---|---|
| 전극 간격 σ_d = 1 mm | — | **4.0 %** |
| Δt 1샘플 (192 kHz) | 5.2 µs | 0.6 % |

**단, σ_d가 어디에 들어가는지는 무엇을 재느냐에 달렸다.**
절대 속도에는 그대로 들어오지만, **개체 내 변화율에서는 d가 전후로 같으면 상쇄된다**
(`v₂/v₁ = Δt₁/Δt₂`). 전극을 매번 다시 대면 그때만 들어온다
→ [`통계_검출력.md`](통계_검출력.md) 「전극 간격 오차는 어디에 들어가고 어디에 안 들어가는가」.

## Δt를 재는 세 가지 방법

### 1. 정점 시각 차 (단계 0의 방법)

이상성 파형의 **첫 번째 음의 정점**끼리 시간차를 읽는다.
오실로스코프 커서로 손으로 읽는다.

- 장점: 즉시 된다. 장비 외에 아무것도 필요 없다
- 단점: 정밀도가 샘플 간격과 사람 눈에 묶인다. 잡음이 정점 위치를 흔든다

**단계 0에서는 이걸로 충분하다.** 목표가 "15–45 m/s 범위에 드는가" 하나이기 때문이다.

### 2. 상호상관 (cross-correlation) — 단계 1 이후 주력

두 채널 파형 전체의 상호상관을 구해 **최대가 되는 지연**을 Δt로 삼는다.

- 파형 **전체**를 쓰므로 정점 하나만 보는 것보다 잡음에 강하다
- 최대점 주변 3점에 **포물선 보간**을 하면 **샘플 간격보다 미세한 분해능**이 나온다

포물선 보간 (y₋₁, y₀, y₊₁이 최대점과 그 이웃):

```
δ = 0.5 · (y₋₁ − y₊₁) / (y₋₁ − 2y₀ + y₊₁)      단위: 샘플
```

192 kHz(샘플 간격 5.2 µs)에서 보간까지 하면 Δt 25 µs는 여유 있게 분해된다.

**전제 1**: 두 채널의 파형 모양이 비슷할 것.
전파 도중 파형이 크게 변하면 상호상관 최대점이 편향된다.
채널 간 파형 모양 비교를 단계 1에서 확인한다.

**전제 2 — 두 채널의 잡음이 무상관일 것. ⚠ 우리 구성은 이걸 어긴다.**

접점을 공유하는 구성(ch1 = C1−C2, ch2 = C2−C3)에서는 **C2의 잡음이
ch1에는 −, ch2에는 +로 들어간다.** 두 채널의 상호상관에 **lag 0에 음의 성분**이 생기고,
그것이 진짜 최대점(lag = Δt)을 밀어 Δt를 편향시킬 수 있다.

접점 공유는 5접점으로 4채널을 얻는 우리 설계의 핵심인데(→ [`../장치/전극.md`](../장치/전극.md)),
**그 대가가 이것이다.** 크기는 아무도 재지 않았다.

**단계 1에서 확인할 것**: 지렁이 없이 잡음만 들어간 상태에서 두 채널의 상호상관을 그려
lag 0 근처에 구조가 있는지 본다. 있으면 ① 접점을 공유하지 않는 채널쌍(ch1↔ch3)을 쓰거나
② 상호상관 대신 각 채널의 정점 시각을 따로 잡는 쪽으로 간다.

### 3. 지연가산 필터 (delay-and-sum) — 다채널의 무기

여러 접점 신호를 **가정한 속도에 맞춰 시간을 밀어 더한다.**
그 속도로 실제 전파되는 성분만 보강간섭하고 나머지는 상쇄된다.

- 속도를 훑으면서 출력을 보면 **속도 스펙트럼**이 나온다 → MGF와 LGF가 분리된다
- **근전위처럼 전파하지 않는 성분은 어떤 속도에서도 보강되지 않는다** → 자동 제거

Yoshida (2009)가 11접점 커프로 쓴 방법이다 (**원문 확인**).

**실측 효과** (Fig. 8, n = 12):

| | 원신호 | 지연가산 후 |
|---|---|---|
| 맞는 속도의 MGF | 29.4 µV | **62.4 µV** (약 2.1배) |
| 맞는 속도의 LGF | 37.1 µV | **68.4 µV** (약 1.8배) |
| **안 맞는 속도** | — | **34 / 26 µV — 변화 없음** |
| 자극 아티팩트 | 58.7 µV | 38.7 µV |

**커프가 길수록(채널이 많을수록) 속도 선택도가 올라간다.**
튜닝 폭(FWHH)은 MGF 약 10–15 m/s, LGF 약 5 m/s —
두 섬유의 속도가 2배 이상 차이나므로 서로 겹치지 않는다.

우리 5접점 4채널 구성이 이걸 노린 것이다 → [`../장치/전극.md`](../장치/전극.md).

### 매치드 필터 — SNR은 올리지만 선택도는 못 올린다

MGF 스파이크의 평균 파형을 템플릿으로 만들어 상관시킨다.
Yoshida 실측: 신호 21.0 µV(MGF)로 줄지만 **잡음이 19.3 → 2.4 µV**로 죽어 **SNR 약 8.8**.
자극 아티팩트도 1.4 µV까지 지워진다.

**단, 저자 결론은 "was not found to improve selectivity"** —
어느 섬유인지 가려내는 능력은 지연가산이 담당하고, 매치드 필터는 SNR만 담당한다.

템플릿을 만들려면 깨끗한 평균 파형이 먼저 필요하므로 **단계 1 이후**의 선택지다.

## 시간 잠금 평균화

자극과 동기해 N회 기록하고 평균 낸다.

- 자극에 시간이 고정된 신경 스파이크는 **살아남는다**
- 무작위 성분은 **√N** 로 줄어든다 (50회면 약 7배)

**N을 얼마로 할지는 실측 잡음 바닥이 정한다.** Yoshida(SNR 1.5–2)를 기준으로 50회를
못박으면 과설계일 수 있다 — 우리 조건에 가까운 Kladt는 20:1을 보고한다
→ [`세포외기록_원리.md`](세포외기록_원리.md).

**전제**: 매 시행의 지연이 일정할 것.
자극 시점 자체가 흔들리면(지터) 평균이 신호를 뭉갠다.
그래서 단계 4에서 **UMC404HD의 출력으로 자극**한다 — 입력과 같은 클럭이라
자극 시점이 샘플 단위로 정확하다 → [`../결정기록.md`](../결정기록.md).

단계 0–1의 기계적 자극(막대로 톡 치기)은 시점이 부정확하다.
그래서 **자극 시점을 쓰지 않고 두 채널의 상대 지연만 쓴다**
(→ [`세포외기록_원리.md`](세포외기록_원리.md)).

## 채널 간 시간정렬 캘리브레이션 ★

**두 채널의 증폭기가 완전히 같지 않으면 그 자체로 지연 차가 생긴다.**
필터의 위상 응답이 조금만 달라도 수십 µs가 나온다 — 우리 목표가 25 µs다.

**반드시 해야 하는 것**: 두 채널 입력에 **같은 신호를 동시에** 넣고
출력의 Δt를 잰다. 이 값이 채널 간 고정 지연이고, 실측 Δt에서 빼야 한다.

- 언제: 단계 1에서 처음, 이후 회로를 만질 때마다
- 어디에 기록: [`../장치/캘리브레이션/색인.md`](../장치/캘리브레이션/색인.md)

디지타이저 자체의 채널 스큐도 여기 포함된다.
Arduino Uno를 기각한 이유가 정확히 이것이다 —
ADC가 하나라 두 채널을 번갈아 읽어 **100 µs 스큐 → CV 12 % 오차**.

## 처리 순서 (단계 1 이후 표준)

1. 원시 파형 로드 — **절대 수정하지 않는다**
2. 대역통과 필터 (300–3000 Hz)
   → **영위상 필터(filtfilt)를 쓴다.** 인과 필터는 채널마다 지연을 넣는다
3. 시행 정렬 · N회 평균
4. 스파이크 구간 잘라내기
5. 상호상관 + 포물선 보간 → Δt_raw
6. **채널 간 고정 지연 빼기** → Δt
7. v = d / Δt
8. MGF / LGF 판별 (속도 범위 + 자극 위치)

**원시 파형만 남긴다. 2번 이후는 전부 파생 데이터이므로 저장하지 않는다**
(→ [`../CLAUDE.md`](../CLAUDE.md) 기록 작성 규칙).

**이 절차를 구현하는 것은 실제 데이터가 나온 뒤의 일이다.**
파일 형식(단계 0 오실로스코프 CSV / 단계 4 WAV)이 정해지기 전에는 짜지 않는다.
