## ✅ 1999 · Drewes — 자유롭게 움직이는 개체에서 비침습 기록

| | |
|---|---|
| **실험체** | ***Lumbriculus variegatus*** (담수 빈모류) — **지렁이가 아니다** |
| 전극 | **인쇄회로기판에 에칭한 평면 전극** 위에 올린다 |
| 구속 | **없음.** 해부 · 마취 · 구속 전부 없음 (freely moving) |
| 증폭 | 전치증폭기 ×100/×1000 · **±9 V 배터리팩** (또는 ±15 V) |
| 스코프 | Tektronix TDS 210 디지털 스토리지 · 통과대역 300 Hz – 3 kHz |
| 얻은 것 | 비침습이 가능한 이유 — 거대섬유는 굵어서 전류가 크고, 체벽·피부의 전기저항이 낮다 |
| 우리에게 | ±9 V 배터리 구성 · 스코프 요구사양 **12 kHz/채널 · 20 ms 캡처 · 내부 트리거** |

**정정**: 초안이 이 논문에 귀속시킨 "표면 신호 0.1 mV 이하"는 **원문에서 확인되지 않는다.**

**전도속도가 안정적이려면 4조건**: 같은 부위 · 직선 정렬 · 일정한 온도 ·
**손상이나 독성으로 신경이 변하지 않았을 것.**
마지막 조건이 곧 우리 실험이 뒤집으려는 전제다.

→ [`../문헌/Drewes1999_비침습기록.md`](../문헌/Drewes1999_비침습기록.md)

## ✅ 2009 · Yoshida, Kurstjens & Hennings — 감싸는 커프 전극 어레이

| | |
|---|---|
| 종 | ***Lumbricus terrestris*** — **우리와 일치**. 성체 12마리 |
| 전극 | 몸 전체를 감싸는 **11접점 백금 링 커프**, 내경 4 mm, 접점 간격 **3 mm** |
| **환경** | **0.9 % 생리식염수에 잠긴 상태.** 머리·꼬리는 바늘로 핀 고정 — **비침습이 아니다** |
| 마취 | 10 % 에탄올 10분 · 실온 21 °C |
| 기록 | 이득 1000× · 고역통과 0.1 Hz · 샘플링 50 kHz |
| 자극 | 100 µs 구형파 · 역치의 2배 · **간격 2초** · **최소 50회 평균** |
| 결과 | MGF **15.6 ± 0.87**, LGF **7.7 ± 0.48 m/s** (mean ± **SEM**, n=12) → 각 CV 약 19 % · 22 % |
| 신호 | MGF **29.4 µV** · LGF **37.1 µV** · 잡음 **19.3 µV** → SNR 1.5–1.9 |
| 발견 ① | 간격이 넓을수록 진폭 증가, **파장에 접근하면 멈춘다.** 삼극 LGF 최대 12 mm, **MGF는 24 mm에서도 증가 중** |
| 발견 ② | **지연가산 필터가 맞는 속도의 신호만 약 2배 증폭**(29.4 → 62.4 µV) |
| 우리에게 | 간격 25 mm 근거 · 접점 공유(§2.3.1) · **자극 간격 2초와 50회 평균의 출처** |

**저자 본인이 에탄올 때문에 값이 절반이라고 적었다** —
"about half of the values reported by [26]... may be due to the ethanol".

**주의**: 이 논문의 "수초" 서술은 **구조적 유사성**에 관한 것이고
분자적 동일성을 뜻하지 않는다 → [`지렁이_해부와생리.md`](지렁이_해부와생리.md).

→ [`../문헌/Yoshida2009_커프전극.md`](../문헌/Yoshida2009_커프전극.md)

## ✅ 2010 · Kladt, Hanslik & Heinzel — 온전한 개체용 프로토콜 9종

| | |
|---|---|
| 종 | ***Lumbricus terrestris*** — **우리와 일치** |
| 전극 | 시침핀이 **배쪽 피부 표면에 닿는다**(뚫지 않는다) · 쌍 간격 **약 1 cm** · 꼬리쪽 40–50 mm |
| 증폭 | 이득 1000배 · 통과대역 0.3 – 3 kHz |
| 마취 | **클로로부탄올 0.2 % · 수돗물 · 10–15분** (증류수 금지) |
| 다루는 실험 | 활동전위 모양·지속시간·역치, 절대/상대 불응기, 전도속도, **온도 의존성**, 전도 촉진 |
| 핵심 수치 | **초정상성 약 10 %** · Q₁₀ ≥ 2(≈ 7 %/°C) · MGF 역치 1.2–2.9 V < LGF 3.2–5.8 V |
| 우리에게 | 전극 배치 · 필터 · **초정상성과 온도의 크기** · 자극·기록 사이 호일 차폐 |

**이중 기록이 정확한 방법이라고 명시**한다 — 우리 방법의 근거.
단계 3 이후 역치·불응기 측정 시 이 프로토콜을 따른다.

## ✅ 2014 · Bähring & Bauer — 마취 없는 자발 진입 챔버

| | |
|---|---|
| 종 | ***Lumbricus terrestris*** — **우리와 일치** |
| 전극 | 바닥에 깔린 **은전극 기록 4쌍 + 접지 2개.** 중앙 2쌍을 상시 사용 |
| 챔버 | **좁은 원형 덕트.** 지렁이가 **강제 없이 스스로 들어온다** |
| 마취 | **없음** |
| 결과 | MGF **30.2 ± 0.7 m/s** — **±0.7은 SE, n=74 시행.** SD ≈ 6.0 (약 20 %), 범위 **10.3–54.8** |
| 자극 | 0.1 ms 펄스 · 역치 평균 1.49 V |
| 용도 | 독일 의대 1학년 실습용 (단회 세션) |
| 우리에게 | **챔버 설계** · 비마취 기준선 · 첫 음의 정점 기준 Δt |

비마취의 진짜 난점은 움직임이 아니라 **자세**다 —
강제로 밀어 넣으면 "배쪽이 전극을 향하지 않는" 실패가 약 30 % 났고, 그래서 챔버를 만들었다.

**주의**: n은 **시행 수이지 개체 수가 아니고**, 며칠 반복 측정은 하지 않았다.
"7일 반복해도 죽지 않는다"는 **우리가 단계 2에서 확인할 가정**이지 이 논문의 결론이 아니다.

→ [`../문헌/Bahring2014_비마취챔버.md`](../문헌/Bahring2014_비마취챔버.md) ·
[`../장치/챔버/설계.md`](../장치/챔버/설계.md)

## ✅ 2014 · Shannon 등 — 사운드카드만으로 전도속도 재기

| | |
|---|---|
| 장비 | SpikerBox 2채널 + 노트북 **사운드카드 + Audacity** |
| 전극 | 금속 핀 3개를 **몸을 관통시켜** 받침까지. 등쪽이 위, 중심선에서 살짝 벗어나게 |
| 마취 | **실험은 전부 10 % 에탄올 5분.** 탄산수 60 %는 "에탄올이 없을 때의 대안"으로만 제시 |
| 결과 | MGF **22.8 ± 4.5 m/s**, LGF **7.6 ± 1.2 m/s** — **±는 개체 간 SD** (7마리 · 개체당 5회) |
| 절차 | LGF와 MGF를 **전극을 옮겨 따로** 잰다. 거리는 매번 자로 실측 |
| 우리에게 | **탄산수 레시피와 마취 확인법** · **±4.5가 개체 간이라는 확인** |

**±4.5가 개체 간 SD라는 것이 중요하다** — 개체 내 전후 비교가 이 변동을 상쇄한다.
**탄산수 조건의 속도는 어느 문헌도 측정하지 않았다.**

→ [`../문헌/Shannon_휴대형전도속도.md`](../문헌/Shannon_휴대형전도속도.md)

## ❌ 2011 · Gooneratne 등 — 산성광산배수(중금속) 노출 ★ 중금속 직접 선행연구

| | |
|---|---|
| 종 | *Aporrectodea caliginosa* (육상) + *Lumbriculus variegatus* (수생) |
| 노출 | **산성광산배수 오염 흙·퇴적물**, 뉴질랜드 광산 지역 15개 지점 |
| 측정 | MGF 전도속도, 0 · 1 · 2 · 4 · 7 · 14 · 21일 |
| 결과 | 대부분의 지점에서 전도속도가 점진적으로 감소. **7일째 가장 뚜렷** |
| 우리에게 | **"중금속 오염이 지렁이 전도속도를 낮춘다"가 이미 한 번 관찰됐다** |

**한계**: 산성광산배수는 혼합물이고 **pH가 2.99–7.66으로 통제되지 않았다.**
금속 효과와 산성 효과가 분리되지 않는다. 용량–반응도 없다.

## ✅ 2018 · Mazzia 등 — 살충제 노출 개체의 전도속도 (방법론의 직접 선행연구)

| | |
|---|---|
| 종 | *Aporrectodea caliginosa* (우리와 다른 종). 기저 NCV **12.83 ± 0.53 m/s** |
| 전극 | **인쇄회로기판 에칭 격자.** 마취·구속 없음. 고무줄로 촉각 자극 |
| 전도 거리 | **10 mm** |
| 신호 | 진폭 20–50 mV(화면값) · **SNR 5:1 – 10:1** · 개체·시점당 3회 평균 |
| 노출 | 카바메이트(Pirimor®) · 유기인계(Lorsban®), 권장 살포량의 0.5× · 1× · 5× |
| 측정 | **같은 개체의 MGF 전도속도를 0 · 1 · 2 · 3 · 4 · 7일에 반복 측정** |
| 결과 | Pirimor 5×에서 **3일째 25 % 저하.** AChE와 R² = 0.914 |
| | **Lorsban은 전 농도·전 시점에서 효과 없음** |
| 우리에게 | **실험 설계 전체** — 반복 측정 일정, 개체 내 비교, 농도 배수 설계 |

중금속에 이 설계(정의된 단일 금속 · 용량–반응 · pH 통제)를 적용한 예는 아직 없다.
