# 이번주 — 2026-09 다음 회차

## 목표

> **① 우리 회로의 출력을 컴퓨터로 녹음해 파일로 남긴다.**
> **② 채널을 2개로 만든다.**
> **③ 신호가 잡히면, 같은 자리에서 Δt 를 10회 반복해 잰다.**

②가 있어야 전도시간을 잴 수 있다. ③은 우리 장치의 측정 흩어짐(σ)을 재는 것이고,
**필요한 개체 수와 검출 가능한 최소 효과가 전부 그 값에 걸려 있다.**

**관문 A–D 와 판정 기준은 [`실험절차.md`](%EC%8B%A4%ED%97%98%EC%A0%88%EC%B0%A8.md) 에 있다.**

## 이번 회차에 하지 않는 것

- **자극 역치** — 자극기가 없다. **손으로 치는 자극에는 역치가 없다**
- **전극과 지렁이 구속** — 챔버팀 몫이다. 커터 칼날은 임시였고 쓰지 않는다

| 오실로스코프로 단발 파형을 못 잡는다 | **컴퓨터 녹음으로 대체** | **신이안** |
