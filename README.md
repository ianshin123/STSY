# STSY — 지렁이 신경 신호로 중금속의 영향을 재려는 연구

> 지렁이는 신경에 **수초와 비슷한 구조**가 있고, **살아 있는 상태에서 신경 신호를 잡기에
> 적합하다.** 그렇다면 **중금속이 신경계에 주는 영향**과, 그것을 **예방하거나 치료하는 물질**을
> 이 지표로 알 수 있을 것 같다.

**이 문장 하나가 연구의 출발점이고, 나머지는 전부 여기서 파생된다.**

STSY(과학기술심포지엄)는 한국 · 중국 · 싱가포르 · 대만 · 말레이시아 5개국이 참가하는
국제교류 연구 프로그램이다. 고2 1학기까지 이어지고, **고2 여름방학에 싱가포르에서 발표한다.**
**이 저장소는 그중 측정장치 파트의 실무 저장소다** — 담당 신이안(북일고등학교).

### ▶ 지금까지의 과정은 [`기록.md`](%EA%B8%B0%EB%A1%9D.md) 에, 지금 쓰는 장치는 [`장치/`](%EC%9E%A5%EC%B9%98/) 에 있다

## 정해진 것

**아래가 결정의 정본이다.** 근거가 된 문헌은 [`문헌/색인.md`](%EB%AC%B8%ED%97%8C/%EC%83%89%EC%9D%B8.md) 에 있다.

### 실험 설계

| 항목 | 정한 것 |
|---|---|
| **종** | ***Lumbricus terrestris*** — 측정 문헌이 전부 이 종이다. OECD 207 권장종(*E. fetida*)과 다르다 |
| **지표** | **전도시간(전도속도) · 자극 역치** 중심. 진폭은 보조 |
| **측정 방법** | **비마취 접촉식 챔버**(Bähring 도면). 마취 + 관통 핀은 실패했다 |
| **기록 장비** | **4채널 이상**을 구매한다 (기종·시기 미정). 1채널로는 전도속도를 못 잰다 |
| **자극기** | **Bähring 논문과 같은 방식으로 자작.** 구형파 · 0.01–1 ms · 0.1 V 단위 가변 · 트리거 출력. **역치 측정에 필수다** |
| **중금속** | **카드뮴 · 납 · 아연** |
| **노출 방식** | **여과지 접촉(48시간) · 토양 함침(7일)** — OECD 207의 틀을 응용 |
| **농도 단위** | **mg/cm² · mg/kg 건조토양** (금속 이온 기준). mM이 아니다 |
| **완화 물질** | 굴껍데기 · 게 껍데기/키토산 · 우롱차 찌꺼기 · 코코넛 껍질 · 두리안 껍질 |
| **처리 순서** | **선처리(예방) · 동시처리 · 후처리(치료)** |

### 장치

| 항목 | 정한 것 |
|---|---|
| **회로** | **AD623 계측증폭기 모듈 × 2.** 2026-09-05 에 모듈이 도착해 TL072 3개 판에서 갈아탔다 |
| **채널** | **2개.** 2번 보드는 1번 보드를 그대로 한 벌 더 만들고 레일 3줄만 끌어온다 |
| **전극** | **3개** — 채널마다 기록 하나 + 두 채널이 기준(접지) 하나를 함께 쓴다. Shannon 과 같다 |
| **전극 방식** | **접촉식.** 시침핀 관통보다 신호가 뚜렷했다 |
| **기록** | **오실로스코프를 아예 안 쓴다** → 컴퓨터 녹음. 그래서 멀티미터를 샀다 |
| **차폐** | **패러데이 상자는 우리 실험실에서 필요하지 않았다.** 1차·2차 모두 차이가 별로 없었다 |
| **구속** | 관은 안 된다 — 여유 공간이 있으면 지렁이가 몸을 비틀어 빠져나간다 |
| **보유 장비** | **OWON HDS1021M-N** 오실로스코프 (1채널 · 배터리 구동). **내장 멀티미터는 고장으로 못 쓴다**(2026-09-06) · **학교 3D 프린터 사용 가능** |

**앰프는 작동한다** — 양쪽 전극을 함께 대면 상쇄되어 0 V가 된다.
**비마취 상태에서 손으로 툭툭 쳤을 때 오실로스코프가 분명히 변했다.**
**잡은 것은 「자극을 주면 화면이 변한다」까지다.** 역치도 전도시간도 자극기와 다채널 기록이
갖춰지기 전에는 숫자로 나오지 않는다.

## 아직 정하지 않은 것 — **신이안이 정한다**

**AI가 이 목록을 채우지 마라.** 조사·검증·계산은 맡길 수 있지만 판단은 그의 몫이다.

- **농도 계열의 실제 상·하한** — 예비 범위탐색이 먼저다
- **적용 부피 · 여과지 넓이 · 건조 토양 질량** — 이것이 정해져야 선량이 나온다
- **아연을 독성 물질로만 쓸지, 완화 후보로도 볼지** (아연이 카드뮴 독성을 낮춘 보고가 있다)
- **챔버를 아크릴 가공으로 만들지 3D 출력으로 만들지**
- **자극기의 구현 회로**
- **4채널 기록 장비의 기종과 구매 시기**
- 완화 물질의 투입량과 45조건을 전부 할지 축소할지
- 3단계 추출 조건과 유효 성분 정량 방법
- 조건당 개체 수와 전체 일정
- **수학모델링캠프의 주제와 모델** — 처음부터 다시 정한다

> ### ⚠ 카드뮴이 이 계보에서 전도속도를 바꾸지 않았다고 인용돼 있다
>
> 우리가 고른 금속은 **카드뮴 · 납 · 아연**인데, O'Gara 2004 §4.3 이 Rogge & Drewes 1993 을
> 인용해 카드뮴은 전도속도를 바꾸지 않는다고 쓴다. **그 원문을 아직 못 봤다** —
