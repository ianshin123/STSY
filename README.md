# STSY — 지렁이 거대신경섬유 전도속도 측정

중금속(납 · 카드뮴)이 신경계에 주는 영향을 지렁이 거대신경섬유의 **전도속도**로
정량하고, 그것을 예방하거나 완화하는 물질을 찾는 연구.

STSY(과학기술심포지엄)는 한국 · 중국 · 싱가포르 · 대만 · 말레이시아 5개국이 참가하는
국제교류 연구 프로그램이다. 고2 1학기까지 이어지고, 고2 여름방학에 싱가포르에서 발표한다.

**이 저장소는 그중 측정장치 파트의 실무 저장소다.** 담당 신이안.
장비 제작 · 스파이킹 측정 · 신호 분석이 여기 들어온다.
중금속 농도 · 노출 방식 · 완화물질 선별은 다른 팀원 몫이고 이 저장소 범위 밖이다.
