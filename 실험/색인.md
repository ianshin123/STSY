# 실험 색인

모든 세션을 한 줄씩. **아직 세션이 없다.**

---

## 폴더 규칙

```
실험/YYYY-MM-DD_단계N_세션명/
├── 메타.md      ★ 없으면 그 데이터는 무효다
├── raw/         ★ LFS. 원시 파형. 절대 수정 금지
└── 결과.md
```

파일명에 **날짜 · 단계 · 개체ID · 조건**이 들어간다.
예: `2026-09-01_S0_W03_carbonated_ch1-2.csv`

---

## `메타.md` 필수 항목 ★

**이게 없으면 그 데이터는 무효다.** 예외 없다.

```markdown
# YYYY-MM-DD 세션명

단계    : 0
목적    : (한 줄)

## 조건
온도        : ___ °C  (측정 시각별로 여러 개면 전부)
개체 ID     : ___     (길이 ___ mm · 지름 ___ mm)
마취        : 없음 / 탄산수 60 % ___ 분 / 에탄올 ___ % ___ 분
구속        : 코르크판 핀 / 챔버 (홈 폭 ___ mm)
전극        : 시침핀 0.6 mm / 은선 0.5 mm
전극 간격   : **실측값** ___ mm  (설계값 ___ mm)
기록 지점 간 거리 d : ___ mm
자극 방식   : 기계적(막대) / 전기(0.1 ms, ___ V)
자극 간격   : ___ 초
자극 위치   : 머리 / 꼬리

## 장비 설정
증폭기      : 이득 ___배 · 통과대역 ___ – ___ Hz
채널 간 고정 지연 보정값 : ___ µs  (장치/캘리브레이션/____ 참조)
디지타이저  : ___ · 샘플레이트 ___ Hz · 분해능 ___ bit
트리거      : ___

## 파일
raw/____.csv  ← 무엇이 들었는지 한 줄씩

## 이상 사항
(중간에 뭐가 달라졌으면 전부. 사실만)
```

**온도 · 전극간격 · 자극방식 · 마취여부 · 장비설정 다섯 개는 반드시 있어야 한다.**
