## 이 논문이 한 것

### 설계

| 항목 | 값 |
|---|---|
| 종 | ***Aporrectodea caliginosa*** — **우리 실험체 *L. terrestris* 와 다른 종** |
| 물질 | 카바메이트 **Pirimor®**(pirimicarb) · 유기인계 **Lorsban®**(chlorpyrifos-ethyl) |
| 농도 | 0(대조) · 0.5× · 1× · 5× (1× = 뉴질랜드 권장 살포량) |
| | 1× 실측: pirimicarb **0.66 mg a.i./kg 흙** · Lorsban **0.53 mg a.i./kg 흙** |
| 노출 방식 | **흙에 스파이킹.** 흙 100 g에 용액 4 mL, 최종 함수율 25 % |
| 개체 | 총 **n = 128**, 용량당 **8마리**, 개체별 용기 분리, **전 실험을 2회 반복** |
| 환경 | **약 17 °C**, 암실, 7일 |
| 측정 시점 | **0 · 1 · 2 · 3 · 4 · 7일** |
| 통계 | 반복측정 ANOVA + Tukey HSD, p < 0.05 |

### 측정 장치 ★ (우리 설계와 직접 비교되는 부분)

| 항목 | Mazzia 2018 | 우리 계획 |
|---|---|---|
| 전극 | **인쇄회로기판에 에칭한 평행 격자선** | 시침핀(단계 0) → 챔버 은접점(단계 2) |
| 마취 | **없음** | 탄산수(단계 0) → 없음(단계 2) |
| 구속 | **없음** | 없음(챔버) |
| 자극 | **작은 고무줄로 앞끝을 가볍게 촉각 자극** | 막대(단계 0) → 전기(단계 2) |
| **전도 거리** | **10 mm** | **25 mm** |
| 기록 | 차동 증폭 → 필터 → **스토리지 오실로스코프 (Tektronix TDS 250)** | 동일 개념 |
| 신호 진폭 | **20 – 50 mV** (증폭 후 화면값) | 100 mV 목표 |
| **SNR** | **약 5:1 – 10:1** | — |
| 평균화 | **개체·시점당 3회 측정의 평균** | 50회 시간잠금 평균 |

장치는 Gooneratne 등 2011의 것을 그대로 썼다.

### 결과

| 항목 | 값 |
|---|---|
| 대조군 기저 NCV | **12.83 ± 0.53 m/s** (0일차) — 실험 내내 유의한 변화 없음 |
| Pirimor® 5× | **3일째 약 25 % 저하** (10 ± 0.094 vs 13.26 ± 0.42 m/s). 4·7일 유지 |
| Pirimor® 1× | 4일과 7일에만 유의. 1×와 5× 사이 유의차 없음 |
| Pirimor® 0.5× | 유의차 없음 |
| **Lorsban® 전 농도** | **어느 시점에도 유의차 없음** |
| AChE | Pirimor 1×·5×에서 유의 감소. Lorsban은 변화 없음 |
| NCV ↔ AChE 상관 | **R² = 0.914** (Pirimor) |
| 체중 | 전 군에서 5–6 % 감소, 군간 유의차 없음 |

## 우리가 가져오는 것

**실험 설계 전체.**

| 가져오는 것 | 우리 적용 |
|---|---|
| 반복 측정 일정 (0·1·2·4·7일) | 단계 3·4에 그대로 |
| **개체 내 반복 측정으로 개체 간 변동을 줄인다**는 명시적 근거 | 통계 설계의 뼈대 |
| 농도 배수 설계 (0.5×·1×·5×) | 농도 4단계 설계의 원형 |
| 용량당 8마리 · 전 실험 2회 반복 | 개체 수 설계의 참고점 |
| AChE 등 기존 지표와의 상관 | 단계 4의 타당성 검증 방법 |
| 온도 17 °C · 암실 | 사육·노출 조건의 참고점 |

**우리는 살충제를 중금속으로 바꾸고, 완화 물질을 추가한다.**

### 이 논문이 우리 설계에 던지는 세 가지

1. **전도 거리 10 mm로도 25 % 효과를 잡았다.**
   우리 25 mm는 더 보수적인 선택이다 — 시간 정밀도에 유리하다.
2. **SNR 5:1 – 10:1은 Yoshida(2009)의 1.5–2보다 훨씬 좋다.**
   PCB 격자 전극 + 무마취 조건의 차이로 보인다(우리 추론).
   Yoshida 값만 보고 평균화 횟수를 정하면 과설계일 수 있다.
3. **개체·시점당 3회 평균이라는 숫자가 우리 설계에 직접 쓰인다.**
   대응표본 검정의 분모가 `√(2/k) × SD_세션` 이라, **k = 3이면 필요 개체 수가 절반 이하로 준다**
   → [`../정리/통계_검출력.md`](../정리/통계_검출력.md).
   다만 이 논문에서 3회로 충분했던 것은 **효과가 25 %였기 때문**이다. 우리 목표는 3 %다.

## 이 논문이 말하지 않은 것 ★

- **중금속에 대해 아무것도 말하지 않는다.** 살충제 논문이다.
  Pirimor·Lorsban은 **AChE 억제제**이고, 중금속은 이온 통로를 때린다. **기전이 다르다.**
  **"살충제에서 됐으니 중금속에서도 된다"는 이 논문이 지지하지 않는 추론이다.**
- ***L. terrestris* 에 대해 말하지 않는다.**
  **기저 NCV가 12.83 m/s로, *L. terrestris* 의 15–45 m/s와 크게 다르다.**
  종이 다르면 속도도 감수성도 다르다.
- **같은 신경독성 계열 안에서도 결과가 갈렸다.**
  Lorsban(유기인계)은 **7일 · 권장 농도의 5배에서도 아무 효과가 없었다.**
  저자들은 노출 방식 · 용량 · 종이 원인일 수 있다고 본다.
  **"신경독성 물질이면 NCV가 떨어진다"는 참이 아니다.** 우리 H₁이 빗나갈 실제 경로다.
- **반복 측정 변동(SD_rep)을 따로 보고하지 않는다.**
  12.83 ± 0.53 (SD 약 4.1 %)은 **8마리에 걸친 개체 간 SD**로 읽어야 한다.
  우리가 필요한 것은 같은 개체 반복 측정의 SD인데, 그 값은 이 논문에 없다.
- **검출 한계를 계산하지 않았다.** 효과가 25 %라 필요가 없었다.
