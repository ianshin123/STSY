## 이 논문이 한 것

### 설계

| 항목 | 값 |
|---|---|
| 종 | ***Aporrectodea caliginosa*** — ***L. terrestris* 가 아니다** |
| 물질 | 카바메이트 **Pirimor®**(pirimicarb) · 유기인계 **Lorsban®**(chlorpyrifos-ethyl) |
| 농도 | 0(대조) · 0.5× · 1× · 5× (1× = 뉴질랜드 권장 살포량) |
| | 1× 실측: pirimicarb **0.66 mg a.i./kg 흙** · Lorsban **0.53 mg a.i./kg 흙** |
| 노출 방식 | **흙에 스파이킹.** 흙 100 g에 용액 4 mL, 최종 함수율 25 % |
| 개체 | 총 **n = 128**, 용량당 **8마리**, 개체별 용기 분리, **전 실험을 2회 반복** |
| 환경 | **약 17 °C**, 암실, 7일 |
| 측정 시점 | **0 · 1 · 2 · 3 · 4 · 7일** |
| 통계 | 반복측정 ANOVA + Tukey HSD, p < 0.05 |

### 결과

| 항목 | 값 |
|---|---|
| 대조군 기저 NCV | **12.83 ± 0.53 m/s** (0일차) — 실험 내내 유의한 변화 없음 |
| Pirimor® 5× | **3일째 약 25 % 저하** (10 ± 0.094 vs 13.26 ± 0.42 m/s). 4·7일 유지 |
| Pirimor® 1× | 4일과 7일에만 유의. 1×와 5× 사이 유의차 없음 |
| Pirimor® 0.5× | 유의차 없음 |
| **Lorsban® 전 농도** | **어느 시점에도 유의차 없음** |
| AChE | Pirimor 1×·5×에서 유의 감소. Lorsban은 변화 없음 |
| NCV ↔ AChE 상관 | **R² = 0.914** (Pirimor) |
| 체중 | 전 군에서 5–6 % 감소, 군간 유의차 없음 |

## 이 논문이 말하지 않은 것 ★

- **중금속에 대해 아무것도 말하지 않는다.** 살충제 논문이다.
  Pirimor·Lorsban은 **AChE 억제제**이고, 중금속은 이온 통로를 때린다. **기전이 다르다.**
  **"살충제에서 됐으니 중금속에서도 된다"는 이 논문이 지지하지 않는 추론이다.**
- ***L. terrestris* 에 대해 말하지 않는다.**
  **기저 NCV가 12.83 m/s로, *L. terrestris* 의 15–45 m/s와 크게 다르다.**
  종이 다르면 속도도 감수성도 다르다.
- **같은 신경독성 계열 안에서도 결과가 갈렸다.**
  Lorsban(유기인계)은 **7일 · 권장 농도의 5배에서도 아무 효과가 없었다.**
  저자들은 노출 방식 · 용량 · 종이 원인일 수 있다고 본다.
  **"신경독성 물질이면 NCV가 떨어진다"는 참이 아니다.**
  같은 계열 안에서도 결과가 갈리는 실제 사례다.
- **같은 개체를 반복 측정했을 때의 변동을 따로 보고하지 않는다.**
  12.83 ± 0.53 (SD 약 4.1 %)은 **8마리에 걸친 개체 간 SD**로 읽어야 한다.
  같은 개체 반복 측정의 SD는 이 논문에 없다.
- **검출 한계를 계산하지 않았다.** 효과가 25 %라 필요가 없었다.
