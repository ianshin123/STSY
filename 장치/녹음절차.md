# 컴퓨터로 녹음하고 재는 법

<sub>**Audacity 를 한 번도 안 열어 봤다는 전제로 쓴 순서다.**
1–5절은 **노트북만 있으면 오늘 연습할 수 있다** — 내장 마이크로 한다. 회로도 인터페이스도 필요 없다.
6절부터가 M-Track Duo 를 꽂았을 때다.
단축키표 · 두 채널 빼기 · 쓰면 안 되는 기능은 [`기록.md`](../%EA%B8%B0%EB%A1%9D.md) 「Audacity — 녹음과 측정」에 있다.</sub>

---

## 0. 먼저 알아야 하는 것 하나 — **세로 눈금은 볼트가 아니다**

Audacity 파형의 세로 눈금은 **−1.0 ~ +1.0** 이고, 이것은 **「녹음이 가득 찬 정도」**다.
**볼트가 아니다.** 인터페이스의 게인 노브를 돌리면 같은 신호도 높이가 달라진다.

여기서 두 가지가 따라 나온다.

| | |
|---|---|
| **못 하는 것** | 파형 높이를 보고 「몇 µV 였다」고 말하는 것. **게인을 모르면 절대 크기가 안 나온다** |
| **되는 것** | ① **상대 비교** — A 가 B 의 몇 배인가 (게인을 안 건드리면 정확하다) ② **시간** — Δt 는 게인과 무관하다 |

**우리가 재려는 것(전도시간 Δt · 잡음이 신호보다 큰가 작은가)은 전부 되는 쪽이다.**
절대 크기가 필요하면 **크기를 아는 신호를 한 번 넣어 견주는 수밖에 없다.**

## 1. Audacity — 어디서 받나

**`audacityteam.org` 가 정본이다.** 이름이 비슷한 다른 사이트에서 받으면 광고 프로그램이 딸려 온다.

---

## 2. 오늘 할 것 — 내장 마이크로 익히기

1. Audacity 를 연다
2. 위쪽 **`Audio Setup`** 단추를 누른다 (옛 버전이면 `Edit ▸ Preferences ▸ Audio Settings`)
   - **Host** → `Windows WASAPI`
   - **Recording Device** → 노트북 내장 마이크
   - **Recording Channels** → `1 (Mono)`
3. **`R`** 키(또는 빨간 동그라미)를 누르면 녹음이 시작된다. **`Space`** 로 멈춘다
4. 파형이 그려져 있다. **이게 전부다** — 녹음을 누르고, 멈추고, 그려진 것을 본다

> ⚠ **Audacity 는 오실로스코프가 아니다.** 실시간 파형 창이 없다.
> 그래서 **계속 녹음해 두고, 자극을 여러 번 준 뒤, 멈추고 본다.**
> 48 kHz · 16 bit · 2채널이면 **분당 11.5 MB** 라 10분을 켜 놔도 부담이 없다.

## 3. 크게 보기 · 작게 보기

| 하고 싶은 것 | 누르는 것 |
|---|---|
| 가로로 확대 · 축소 | **`Ctrl`+`1`** · **`Ctrl`+`3`** |
| 고른 구간을 화면에 꽉 | **`Ctrl`+`E`** |
| 전체 보기로 되돌리기 | **`Ctrl`+`F`** |
| **세로로 확대** | 트랙 **왼쪽 세로 눈금자를 클릭** (`Shift`+클릭 = 축소) |

**세로 확대가 우리한테 제일 중요하다.** 조용한 구간은 그냥 보면 일직선인데,
세로로 확대하면 그 안에 지지직(잡음)이 보인다. **잡음 바닥을 보는 것이 이 동작이다.**

---

## 4. 시간 재기 — 표시를 `samples` 로 바꾼다

1. 화면 아래 **선택 도구모음**의 시간 숫자 옆 작은 **▼** 를 누른다
2. 표시 형식을 **`samples`** 로 바꾼다
3. 파형의 한 점을 클릭하면 그 자리의 **샘플 번호**가 나온다

**48 000 Hz 에서 1 샘플 = 20.8 µs.**
두 점의 샘플 번호를 빼면 그 사이 시간이 나온다 — **이것이 Δt 를 재는 전부다.**

---

## 5. 어떤 주파수가 실렸나 — `Analyze ▸ Plot Spectrum`

구간을 드래그해 고르고 **`Analyze ▸ Plot Spectrum`**.
가로축이 주파수, 세로축이 세기다. **60 Hz 에 뾰족한 봉우리가 서 있으면 전원 잡음이다.**

### 오늘 해 볼 연습 다섯

1. 5초 녹음 — 조용히 있다가 중간에 한 번 말한다. **말한 곳만 파형이 커진다**
2. 조용한 부분을 골라 **세로 눈금자를 여러 번 클릭**한다. 지지직이 보인다 → **이것이 잡음 바닥이다**
3. **손뼉을 두 번** 친다. 표시를 `samples` 로 바꾸고 두 손뼉의 **시작점** 샘플 번호를 읽어 뺀다.
   48 000 으로 나누면 초다. 초시계와 대충 맞는지 본다 → **Δt 재기와 똑같은 동작이다**
4. 「아—」 하고 한 음을 낸 구간을 골라 **Plot Spectrum**. 봉우리가 하나 선다
5. **`File ▸ Export`** (버전에 따라 `Export ▸ Export as WAV` 또는 `Export Audio…`) 로 WAV 저장

**이 다섯이 되면 다음주에 회로에서 할 일은 같은 동작의 반복이다.**

## 6. 다음주 — M-Track Duo 를 꽂을 때

### 순서를 지킨다 — 드라이버가 먼저다

사용설명서 원문: *"Windows users: **Before connecting** M-Track Duo to your computer, install the drivers"*
(`m-audio.com/drivers`). **번들 음악 프로그램(MPC Beats 등)은 안 깔아도 된다 — 드라이버와 다른 것이다.**

### 앞면 스위치 세 개

| 스위치 | 어디로 | 왜 |
|---|---|---|
| **Line / Instrument** (채널마다 하나) | **Instrument** | 불평형 6.35 mm · 입력 임피던스 1 MΩ — 우리 회로에 맞는다 |
| **+48 V 팬텀** (하나로 두 입력에 함께) | **끈다** | 마이크용 48 V 다. 우리 회로에 걸릴 이유가 없다 |
| Direct Mono / Direct Stereo / **USB** | **USB** | 헤드폰으로 들리는 것만 정하는 스위치다. 녹음에는 영향이 없다 |

### 윈도우 소리 설정

`소리 제어판 ▸ 녹음` 탭 → **`USB Audio Codec`** 을 기본 장치로 →
`속성 ▸ 고급` → **`2채널 · 16비트 · 48000 Hz`** → **`독점 모드` 체크 두 개를 끈다**

### Audacity 설정

**Host `Windows WASAPI` · Recording Device `USB Audio Codec` · Recording Channels `2 (Stereo)`
· Project Rate `48000`**

> ⚠ **Audacity 공식 배포판에 ASIO 는 없다** — 라이선스가 충돌해서 넣을 수가 없다.
> **우리는 필요 없다.** ASIO 는 실시간 모니터링 지연을 줄이는 것이고 우리는 녹음해서 나중에 잰다.
> 사용설명서가 ASIO 를 고르라고 하는 것은 번들 DAW 이야기다.

### 게인 노브

윗면 노브 2개. **파형이 화면 절반쯤 차게** 맞춘다.
**Signal/Clip LED 가 빨개지면 내린다** — 빨간 것은 신호가 잘려 나가고 있다는 뜻이다.

> ★ **한 번 맞춘 게인 노브는 그 세션 동안 건드리지 않는다.**
> 0절에서 본 대로 Audacity 는 상대 비교만 정확한데, 노브를 돌리면 그 기준이 무너진다.
