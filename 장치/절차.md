# 1. 조립 — 건전지를 빼 놓고 한다

1. **`Rb2` 를 100 kΩ 으로 바꾼다** (두 보드 다)
2. 나머지는 도면 그대로인지 눈으로 훑는다
3. **오디오 케이블 두 가닥과 전극 리드선을 케이블타이로 나란히 묶는다** — 선이 벌어지면 그 사이가 고리가 되어 60 Hz 를 줍는다
4. **마스킹테이프로 어느 선이 채널 1 이고 2 인지 적는다** — 바꿔 물면 Δt 의 부호가 뒤집힌다

---

# 2. 전원을 넣기 전에 — 멀티미터로

> **저항 측정은 건전지를 뺀 상태에서 한다.** 칩이 안 켜져 있으면 칩 속을 지나 수십 kΩ~MΩ 이 읽히는데 그건 정상이다.
> **10 Ω 아래로 나오는 것만 「붙어 있다」로 본다.**

## 2-1. AD623 모듈 — 보드에 꽂기 전에, 모듈만 따로

| 어디와 어디 | 나와야 하는 것 | 10 Ω 아래로 나오면 |
|---|---|---|
| **`GND` ↔ `−VS`** | 붙어 있지 않아야 한다 | **꽂지 마라.** 회로의 0 V 가 −4.5 V 로 단락된다 |
| `GND` ↔ `+VS` | 붙어 있지 않아야 한다 | 〃 |
| **`IN+` ↔ `GND`** | 붙어 있지 않아야 한다 | **칩 아래 `102`(1 kΩ) 가 입력에 물린 것이다.** 전극 신호가 30~300분의 1 로 깎인다 |
| **`IN−` ↔ `GND`** | 붙어 있지 않아야 한다 | 〃 |
| `REF` ↔ `GND` | 어느 쪽이어도 된다 | 우리는 어차피 REF 를 GND 에 묶는다 |

**모듈 두 개 다 잰다.** 결과를 그대로 적어 둔다 — 이 값이 아직 저장소에 없다.

## 2-2. 브레드보드

| 어디에 | 나와야 하는 것 | 아니면 |
|---|---|---|
| 레일 한 줄의 양 끝 (도통) | 삐 소리 | 30열 부근에서 끊겨 있다. 무는 것은 전부 **28열 왼쪽** |
| **전극 ① 자리 ↔ 전극 ③ 자리** | 무한대 | 붙어 있으면 두 입력이 단락돼 신호가 0 이 된다 |
| **9 V 건전지 자체** | **8.5 V 이상** | 8.0 V 아래면 TL072 가 규격 밖이다. **새것으로 바꾼다** |

## 2-3. 전원부만 먼저 — 여기서 안 나오면 다음으로 안 간다

건전지를 물리고, **검정 탐침을 GND 레일**에 대고:

| 빨강 탐침 | 나와야 하는 것 |
|---|---|
| **V+ 레일** | **+4.5 V** 쯤 |
| **V− 레일** | **−4.5 V** 쯤 |

**둘 다 나오면 가상접지(회로의 0 V)가 제대로 만들어진 것이다.**
한쪽만 나오거나 0 V 면 R1 · R2 · TL072 · 20열 점퍼를 다시 본다.

# 6. 관문 A·B — 손가락 테스트

**이 한 가지가 회로 전체가 살아 있는지를 5분에 가른다.**

1. 건전지 · USB · Audacity 순으로 연결하고 **녹음을 시작한다**
2. **전극 ① 악어클립의 쇠 부분을 손가락으로 잡는다** — 3초 잡았다 3초 뗀다
3. **전극 ② 로 똑같이 한다**
4. `Space` 로 멈추고 파형을 본다

| 보이는 것 | 뜻 |
|---|---|
| 잡을 때만 **파형이 크게 출렁인다** | **그 채널은 살아 있다.** 건전지 → 앰프 → 필터 → 케이블 → 인터페이스가 전부 통했다 |
| 아무 변화가 없다 | 그 보드가 죽었다 → 10절로 |
| 잡지 않아도 계속 출렁인다 | 게인이 너무 높거나 60 Hz 를 심하게 줍고 있다 |

**왜 되나** — 사람 몸은 벽 속 전선의 60 Hz 를 안테나처럼 줍는다. 그게 전극으로 들어가 증폭된다.
**지렁이 신호보다 수백 배 크다.**

★ **여기서 크게 출렁이면, 2-1절의 `102`(1 kΩ) 가 입력에 물려 있을 가능성은 사실상 없다.**

**★ 곧바로 `File ▸ Export audio…`(`Ctrl`+`Shift`+`E`) 로 WAV 를 만든다 — 이것이 관문 A 다.**
**`Channels` 를 `Stereo` 로 둔다** — `Mono` 로 내보내면 두 채널이 합쳐져 Δt 가 사라진다.

# 7. 관문 C — 잡음 바닥 · 이득 · 두 채널 맞추기

## 7-1. 이득 트리머 맞추기

**「포화」란 앰프가 낼 수 있는 최대치에 붙어 아무것도 안 나오는 상태다.**

1. 두 모듈의 트리머를 **한쪽 끝까지** 돌린다 (이득 최소)
2. 손가락을 전극에 댄 채 **조금씩 올린다**
3. 파형이 화면 절반쯤 차면 멈춘다
4. **올렸는데 갑자기 아무것도 안 나오면 그게 포화다 — 도로 내린다**

**트리머를 몇 바퀴 돌렸는지 적어 둔다.**

## 7-2. 잡음 바닥

1. **전극 ① 과 전극 ③ 악어클립을 서로 물린다** (입력을 막는 것)
2. **게인 노브를 건드리지 말고** 30초 녹음
3. **트랙 왼쪽 세로 눈금자를 클릭**해 뜨는 창에서 세로로 확대하고, `Ruler format` 을 **`Linear (dB)`** 로 바꾼다
4. **잡음 바닥을 dB 숫자로 읽어 적는다** (「띠 두께」 눈대중보다 정확하다) →
   [`장비익히기.md`](%EC%9E%A5%EB%B9%84%EC%9D%B5%ED%9E%88%EA%B8%B0.md) 3-7절

> **Rb2 를 바꾼 효과가 여기서 보인다.** 1 MΩ 이던 때의 계산값이 약 9.5 µV, 100 kΩ 이면 약 4.1 µV 다
> (전극경로 30 kΩ 가정 · **이 가정에서의 계산**). 비교할 지난 실측이 없으므로
> **이번 값이 앞으로의 기준이 된다.**

## 7-3. 두 채널 시간 어긋남과 이득비 — **처음 한 번만**

1. **전극 ① 과 ② 를 서로 물려 한 점으로 만든다**
2. 녹음하면서 그 점을 **손톱으로 톡 친다** — 두 채널에 같은 순간의 신호가 들어간다
3. 두 채널에서 **그 신호가 시작하는 샘플 번호**를 각각 읽어 뺀다 → **시간 어긋남**
4. 두 채널의 **파형 높이 비** → **이득비**

**48 kHz 에서 1 샘플 = 20.8 µs.** 어긋남이 0~1 샘플이면 정상이다.
**여기서 나온 어긋남이 그대로 Δt 의 오차다.** 크게 나오면 적어 두고 나중에 빼야 한다.

# 8. 관문 D·E — 지렁이

- **마취하지 않는다.** 수돗물로 헹구고 물기를 뺀 뒤 마르지 않게 한다
- 전극 **3개** — 채널마다 기록 하나 + 두 채널이 기준(접지) 하나를 함께
- **관통하지 않는다. 표면에 댄다.** 날·핀은 **몸을 가로질러** 대고 몸을 따라 세로로 대지 않는다
- **접지 전극은 기록 쌍의 바깥쪽**에 둔다. 두 기록 전극 사이에 두지 않는다
- **두 기록 전극의 중심 ↔ 중심 거리를 자로 잰다** — 없으면 전도속도가 안 나온다

**녹음을 계속 켜 두고**, 탐침으로 **아주 가볍게 단발** 자극을 **2초 이상 간격**으로 준다.
껐다 켜지 않는다. **머리 쪽과 꼬리 쪽을 나눠서** 한다.

## 잡힌 것이 진짜 신호인지 가리는 법 — 관문 D 의 판정

| 확인 | 진짜라면 |
|---|---|
| **자극 지점에 가까운 채널이 먼저** | 머리를 치면 채널 1 이 먼저, 꼬리를 치면 채널 2 가 먼저 — **Δt 의 부호가 뒤집힌다** |
| 두 채널의 **극성 순서가 같다** | Drewes 1999 의 두 판별 기준 |
| **머리 자극(MGF)이 꼬리 자극(LGF)보다 빠르다** | 문헌상 3–4배. 같은 거리에서 Δt 가 3–4배 차이 나야 한다 |

**부호가 안 뒤집히면 잡힌 것은 신호가 아니라 자극 아티팩트일 가능성이 높다.**

## 관문 E — Δt 10회

신호가 한 번이라도 잡히면 **전극을 건드리지 말고** 자극을 10번 더 주고 **Δt 10개를 전부 적는다.**
여유가 있으면 전극을 뗐다 다시 붙여 3회 더.
**왜 10회인지**는 [`기록.md`](../%EA%B8%B0%EB%A1%9D.md) 「왜 Δt 를 10회 반복하나」에 있다.

# 10. 안 되면 — 어디부터 보나

| 증상 | 순서 |
|---|---|
| **아무것도 안 잡힌다** | ① 손가락 테스트(6절) → ② 전원부 전압(2-3절) → ③ 전극 접촉 → ④ 케이블·채널 표시 |
| **한쪽 채널만 안 나온다** | 그 보드만 다시 점검 · **케이블을 바꿔 꽂아 본다** (보드 문제인지 케이블 문제인지 갈린다) |
| **손가락 테스트도 안 된다** | 2-3절의 ±4.5 V 부터 다시. 그것도 안 나오면 2-1절 모듈 도통 |
| **60 Hz 가 신호를 덮는다** | **노트북을 배터리로** (충전기를 꽂으면 60 Hz 가 실린다) · 리드선 묶기 · 알루미늄 호일 케이지를 GND 레일에 물린다 |
| **Δt 의 부호가 안 뒤집힌다** | 자극 아티팩트를 보고 있을 가능성. 자극 지점과 기록 지점 사이의 접지·거리를 본다 |
| **레벨이 안 잡힌다** | Input Gain 노브 · Instrument 스위치 · 팬텀이 꺼졌는지 |
| **파형이 안 그려진다** | 녹음 채널이 2 인가 · 장치가 `USB Audio Codec` 인가 |

**조건**: 날짜·시각 · 실온 · 컴퓨터 전원(배터리/콘센트) · 챔버를 썼나 · 마취(무엇으로·몇 분) ·
전극 재료·모양·관통 여부 · **트리머를 몇 바퀴 돌렸나** · Input Gain 노브 위치

**장치 (관문 A·B·C)**: 모듈 도통 측정값(2-1) · 건전지 전압 · V+ / V− 실측 ·
잡음 바닥 · 60 Hz 봉우리 · 채널 간 시간 어긋남(샘플) · 두 채널 이득비 · 손가락 테스트 결과

머리/꼬리 자극에서 어느 채널이 먼저 · 머리/꼬리 자극 Δt · 파일 이름 ·
