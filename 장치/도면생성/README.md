# 도면 생성 스크립트

`장치/그림/`의 도면과 조립 자료 PDF 두 부(**AD623 판** · **TL072 판**)를 만드는 코드다.
**도면을 고칠 때는 PNG를 직접 편집하지 말고 여기 스크립트를 고친 뒤 다시 돌린다.**

> ### ⚠ 이것은 「그리는 코드」다
>
> [`CLAUDE.md`](../../CLAUDE.md)는 이 저장소에 코드를 두지 않는다고 정한다.
> 그 규칙은 **AI가 지시 없이 시뮬레이터를 돌려 낸 수치가 「확정된 것」으로 승격된 사고**에서 나왔다
> ([`정정기록.md`](../../%EC%A0%95%EC%A0%95%EA%B8%B0%EB%A1%9D.md) 「코드를 전부 지웠다」).
>
> 여기 있는 것은 **도면을 그리는 코드일 뿐 어떤 수치도 만들어내지 않는다.**
> 도면에 적히는 값은 전부 [`../회로도.md`](../%ED%9A%8C%EB%A1%9C%EB%8F%84.md)와
> [`../장비.md`](../%EC%9E%A5%EB%B9%84.md)에서 사람이 정한 것을 옮긴 것이다.
>
> **분석·시뮬레이션 코드는 여전히 이 저장소에 두지 않는다.**

## 도면 스크립트가 그리는 방식

세 스크립트 모두 **문자열로 SVG 를 직접 쌓아 올린 뒤 `cairosvg` 로 PNG 를 뽑는다.**
`o=[]; a=o.append` 로 SVG 조각을 모으고 마지막에 `'\n'.join(o)` 한다.

### 브레드보드 좌표계 (`전체연결도.py` · `브레드보드_배치도.py`)

**구멍 한 칸 = 2.54 mm = `P` 픽셀(32).** 실물 치수를 그대로 화면에 옮긴다.

```python
cx(c)   # 열 번호 c 의 x 좌표
Y(r)    # 행 이름 r 의 y 좌표. 'A'–'J' 는 터미널, 'TV','TG','BG','BV' 는 레일
```

그래서 결선표의 `(5, B)` 는 코드에서 `wire((5,'B'), ...)` 로 그대로 쓴다.
**결선표를 고치면 스크립트의 `wire()` · `part()` 줄을 같은 값으로 고친다.**

| 함수 | 하는 일 |
|---|---|
| `wire(p1,p2,색)` | 수–수 점퍼선. 양끝에 점을 찍는다 |
| `part(p1,p2,이름,몸통색,폭,lp)` | 저항·커패시터. `lp` 는 이름표 좌표 |
| `wirepath(경로,색,두께)` | 보드 바깥 배선. **흰 테두리를 먼저 깔아** 교차점에서 위/아래가 보이게 한다 |
| `R([점,점,…],반경)` | 모서리를 둥글린 꺾은선 경로를 만든다 |
| `post(x,y,색,번호)` | 시침핀 기둥 자리에 번호 붙은 동그라미 |
| `female/male/gator(x,y,회전,색)` | 암 커넥터 · 수 커넥터 · 악어클립 그림 |
| `T(x,y,글,크기,색,굵기,정렬)` | 글자 |
| `panel(x,y,w,h,제목)` | 테두리 있는 구역 |

### 색 (실물의 종류를 나타낸다 — 역할이 아니다)

```python
JMP='#1a5fb4'   # 수–수 점퍼선
ALG='#0f9b8e'   # 악어클립 테스트 리드선
SNP='#8e44ad'   # 건전지 스냅 연선
PRB='#2f2f2f'   # 오실로스코프 프로브
RAILR='#e2a8a8'; RAILB='#aab8dd'   # 보드에 인쇄된 레일 줄 (전선이 아니다)
ORG='#c0392b'   # 경고
GRY='#9a9a9a'   # 부품 다리 · 시침핀
```

`RED=JMP; BLU=JMP; …` 로 옛 이름을 새 색에 묶어 두었다. 색을 다시 나누려면 이 줄만 고치면 된다.

### 모듈 바닥 면적

AD623 모듈 기판이 핀 배열보다 크다는 것을 주황 점선 사각형으로 그린다.
`MOX0,MOX1,MOY0,MOY1` 이 그 범위이고, 큰 고정 구멍 2개는 2열 E·F행에 이중 원으로 그린다.
**실물 치수를 아직 재지 않았으므로 넉넉히 잡은 값이다.** 재고 나면 이 네 숫자를 고친다.

> **주의 — 브레드보드 그림이 두 스크립트에 중복돼 있다.**
> `전체연결도.py` 앞부분과 `브레드보드_배치도.py` 가 같은 배선을 각각 그린다.
> **결선을 고칠 때는 반드시 두 파일을 같이 고친다.** 한쪽만 고치면 두 도면이 어긋난다.
> **판이 두 개(AD623 · TL072)이므로 파일은 넷이다.**
>
> **2026-08-29에 실제로 어긋났다** — 레일의 빈 구멍을 `배치도` 두 개에만 그리고
> `전체연결도` 두 개에는 안 그려서, **실험실에 들고 가는 쪽(전체연결도)만 레일이 이어져 보였다**
> (→ [`../../정정기록.md`](../../%EC%A0%95%EC%A0%95%EA%B8%B0%EB%A1%9D.md)).
> **네 파일이 같은 규칙을 쓰는지 매번 확인한다:**
>
> ```sh
> grep -n "hole(cx(c),yy" 전체연결도.py 브레드보드_배치도.py \
>                         전체연결도_TL072IA.py 브레드보드_배치도_TL072IA.py
> # 네 줄 모두 c%6!=RAILGAP 조건이 있어야 한다
> ```
> 고친 뒤에는 아래 검사를 돌려 한 구멍에 두 개가 들어가지 않는지 확인한다.

### 한 구멍에 두 개가 들어가는지 검사

실제로 이 사고가 있었다 — 결선표 21번과 22번이 같은 구멍 `(10,G)` 를 쓰고 있었다.

```python
import re, io, collections
s = io.open('전체연결도.py', encoding='utf-8').read()
use = collections.defaultdict(list)
for m in re.finditer(r"wire\(\((\d+),'(\w+)'\),\((\d+),'(\w+)'\)", s):
    c1, r1, c2, r2 = m.groups()
    use[(int(c1), r1)].append('점퍼선'); use[(int(c2), r2)].append('점퍼선')
for m in re.finditer(r"part\(\((\d+),'(\w+)'\),\((\d+),'(\w+)'\),'([^']+)'", s):
    c1, r1, c2, r2, nm = m.groups()
    use[(int(c1), r1)].append(nm); use[(int(c2), r2)].append(nm)
for k, v in sorted(use.items()):
    if len(v) > 1: print(k, v)     # 아무것도 안 나와야 한다
```

IC 핀과 시침핀 기둥 자리는 위 정규식에 안 잡히므로 필요하면 손으로 더한다.

### 레일에 구멍이 없는 자리인지 검사

**레일 구멍은 5개마다 한 칸씩 비어 있다 — 0열부터 다섯 개(0–4)가 한 묶음이고
`5 · 11 · 17 · 23 · 29` 열에 구멍이 없다** (2026-08-29 · 신이안 현물 확인).
터미널 열에는 이런 빈 칸이 없다.
**네 스크립트가 모두 `RAILGAP=5` 상수를 쓴다 — 위상이 다른 보드를 쓰면 그 숫자 하나만 고친다.**

```python
RAILS = {'TV', 'TG', 'BG', 'BV'}
for (c, r), what in use.items():          # 위 검사에서 만든 use
    if r in RAILS and c % 6 == RAILGAP:          # RAILGAP = 5
        print(f'✗ {r} 레일 {c}열에는 구멍이 없다 — {what}')
```

**`use` 를 만들 때 `for c in (7, 16):` 같은 루프 안의 좌표를 빠뜨리지 마라.**
리터럴만 훑는 정규식은 루프를 못 본다 — 실제로 Cd 두 개를 그렇게 놓쳤다.

> **레일은 통째로 한 덩어리라** 구멍이 어긋나면 옆 구멍에 꽂아도 전기적으로 같다.
> 그래도 도면은 맞춰 둔다 — 조립하는 사람이 그림과 실물이 다르면 멈추게 된다.

### 소자가 남의 구멍 위를 지나가는지 검사 — **위 검사만으로는 안 된다**

「구멍 중복 없음」은 **도면 위에서** 안 겹친다는 뜻이지, 실물에서 안 닿는다는 뜻이 아니다.
저항은 두 구멍 사이에 **누워서** 그 사이 열 위를 지나간다. 2026-08-28에 이걸 안 세어서
**맨 리드끼리 닿을 수 있는 자리가 다섯 곳** 남아 있었다
(→ [`../../정정기록.md`](../../%EC%A0%95%EC%A0%95%EA%B8%B0%EB%A1%9D.md)).

```python
# 위 검사에서 만든 use 를 그대로 쓴다
RAILS = {'TV', 'TG', 'BG', 'BV'}
for m in re.finditer(r"part\(\((\d+),'(\w+)'\),\((\d+),'(\w+)'\),'([^']+)'", s):
    c1, r1, c2, r2, nm = m.groups()
    if r1 != r2 or r1 in RAILS:      # 같은 행에 누운 것만
        continue
    lo, hi = sorted((int(c1), int(c2)))
    for c in range(lo + 1, hi):
        under = use.get((c, r1))
        if under and under != ['점퍼선']:
            print(f'⚠ {nm} 가 {r1}행 {c}열의 {under} 리드 위를 지나간다')
```

**점퍼선 위는 무해하다** — 금속 핀이 플라스틱 몸체 안에 들어 있다.
**맨 리드(저항·커패시터) 위가 문제다.** 나오면 **둘 중 하나를 같은 열의 다른 행으로 옮긴다** —
같은 열이면 노드가 같아 회로는 안 바뀐다.

> **여유가 얼마나 되는지도 봐라.** 1/4 W 금속피막 저항의 몸통은 **6.3 mm**,
> 세라믹 커패시터는 **4 mm** 쯤이다. 구멍 간격이 2.54 mm 이므로
> **4열(10.2 mm) 건너뛰면 몸통이 간신히 덮고, 5열 이상이면 맨 리드가 드러난다.**

## PDF 묶음 (`조립자료_pdf.py`)

**마크다운 → HTML → Chromium 인쇄** 순서다.

1. `md2html()` 이 `../회로도.md` · `../장치설명.md` 를 읽어 HTML 로 바꾼다
   (`markdown` 의 `tables` 확장). **PDF 에서는 눌리지 않으므로 파일 링크는 글자만 남긴다.**
2. `img()` 가 PNG 를 base64 로 넣는다. 그래서 HTML 한 파일만으로 완결된다 (약 2 MB).
3. 표지 · 도면 4쪽 · 본문을 `<section>` 으로 쌓는다. `page-break-after: always`.
   **두 판의 형식이 같다** — 전체 연결도 · 기호표 · 브레드보드 배치도 · 회로 원리도 순서까지.
4. Chromium 헤드리스가 `--print-to-pdf` 로 찍는다.

인쇄 설정은 `<style>` 안에 있다.

| 규칙 | 뜻 |
|---|---|
| `@page { size: A4 landscape; margin: 12mm 14mm }` | 가로 A4 |
| `.fig img { max-height: 165mm }` | 도면이 한 쪽에 들어가게 |
| `.text { column-count: 2 }` | 본문은 2단 (가로 A4 라 한 단이면 줄이 너무 길다) |
| `table { break-inside: avoid }` · `h3 { break-after: avoid }` | 표가 쪽 사이에서 잘리거나 제목만 남는 것을 막는다 |

**내용을 바꾸려면**: 표지와 「조립 전에 확인할 것」은 스크립트 안에 직접 적혀 있고,
본문 절은 마크다운을 그대로 읽어 온다. **그 문서를 고치면 PDF 는 다시 돌리기만 하면 된다.**

**`조립자료_TL072_pdf.py` 의 `md2html(cuts=…)`** 는 마크다운 가운데 토막을 들어내는 인자다.
`../장치설명.md` 의 4-2·4-3절이 AD623 소자 전용이라 TL072 판에서는 그 두 절을 빼고
`../TL072계측증폭기.md` 2-1절로 보낸다. **같은 사실을 두 곳에 적지 않기 위한 장치다.**

## `md2docx.py`

`python-docx` 로 마크다운을 Word 문서로 바꾼다. 제목·문단·표·인용·목록을 처리한다.
본문 Noto Serif CJK KR 10.5 pt, 줄간격 1.6, 전부 검정 — 학교 제출용으로 평범하게 맞춘 값이다.
