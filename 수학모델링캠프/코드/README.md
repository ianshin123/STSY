## 모듈

### `src/hh.py` — 막 한 조각

| 함수 | 하는 일 |
|---|---|
| `Membrane` | 막 파라미터 한 벌. **중금속이 들어오는 자리가 여기다** |
| `Membrane.with_metal(...)` | 금속 효과를 얹은 새 파라미터. 원본은 안 건드린다 |
| `rates(v, shift_mv)` | 게이팅 속도상수 6개. `shift_mv` 가 표면전하 효과 |
| `steady_state(v)` | 정상상태 m·h·n. 시뮬레이션 초기값 |
| `resting_potential(mem)` | 이온 전류 합이 0인 전압을 이분법으로 |
| `phi(temp_c)` | 온도 계수. **모델에서 온도가 들어오는 유일한 통로** |

`resting_potential` 이 따로 있는 이유: 금속을 넣으면 정지전위 자체가 움직인다.
−65 mV 에서 출발시키면 자극 없이도 막이 표류해, **중금속 효과인지
초기값 오류인지 구별할 수 없게 된다.**

### `src/axon.py` — 조각을 이어 붙인 케이블

| 이름 | 하는 일 |
|---|---|
| `Axon` | 지름 · 길이 · dx · 세로저항 · 막 |
| `Axon.max_stable_dt()` | 명시적 오일러의 안정 한계. **넘으면 nan 대신 설명이 나온다** |
| `simulate(...)` | 풀어서 `Run` 을 돌려준다 |
| `Run.conduction_velocity(x0, x1)` | **참값** 전도속도 (막전위 정점 기준) |
| `Run.propagated()` | 끝까지 갔는가 — 발화 확률의 판정 기준 |

### `src/recording.py` — 전극이 보는 것 ★

**모델과 실험을 잇는 다리다.** 선전류원 근사로 세포외 전위를 만든다.

| 함수 | 하는 일 |
|---|---|
| `monopolar(run, x_e)` | 한 점의 전위 [µV] |
| `bipolar(run, x1, x2)` | 두 접점의 차동 — **우리 장치가 실제로 잡는 신호** |
| `channel_pair(run, span_mm)` | STSY 전극 배치를 흉내낸 두 채널 |
| `resample(t, y, fs)` | 시뮬레이션 격자 → 192 kHz |
| `add_noise(y, rms_uv)` | 전극 단 잡음. **축삭을 다시 풀 필요가 없다** |

### `src/metals.py` — 금속 셋

**이 파일의 상수 중 문헌에서 온 것은 하나도 없다.**
근거의 층위는 [`../정리/금속별_기전.md`](../정리/금속별_기전.md)에.

| 이름 | 하는 일 |
|---|---|
| `occupancy(c, k)` | 결합 점유율 (Langmuir/Hill) — **차단형** |
| `cumulative_damage(c, days, k)` | 농도×시간 누적 손상 — **손상형** |
| `LEAD` · `CADMIUM` · `IRON` | 금속 셋. 철만 `time_dependent=True` |
| `iron_u_curve(c)` | 필수 원소의 U자 곡선 |

### `src/sweep.py` — 문서의 표를 만드는 곳

정리/ 아래 노트의 숫자 표는 **전부 이 파일이 뽑은 것**이다.
표를 고칠 일이 생기면 문서를 손으로 고치지 말고 여기를 고쳐 다시 뽑는다.

### `src/colab.py` — 코랩 잡일

경로 잡기 + 한글 폰트. 노트북 첫 칸에서 `colab.setup()` 하나면 된다.

## 검증에서 나온 수치 ★

| | 값 |
|---|---|
| 전 구간 오차 (잡음 없음) | **0.028 %** |
| 전 구간 오차 (19.3 µV 단발) | **최대 0.242 %** |
| dx 100 → 50 µm 수렴 | 0.6 % |
| 세포외 진폭 | 92 µV (문헌 29.4 µV — 자릿수 일치, 3배 큼) |
| 무수 모델 최고 속도 (70 µm) | **7.48 m/s** (MGF 하한 15 의 절반) |
| 전도속도 Q₁₀ | **1.34 → 약 3 %/°C** |

**0.242 % 를 SD_rep 예측으로 읽지 마라.** 전극 위치 오차 · 접촉 임피던스 ·
60 Hz · 근전위가 전부 빠져 있다.

## 시험

```bash
python3 -m pytest 수학모델링캠프/코드/tests/ -q
```

| 파일 | 지키는 것 |
|---|---|
| `tests/test_hh.py` | 교과서 정상상태값 · 정지전위 −65 mV · 특이점에서 nan 없음 |
| `tests/test_axon.py` | `v ∝ sqrt(d)` · dx 수렴 · 안정 한계 · 전도 차단 |
| `tests/test_recording.py` | 진폭 자릿수 · **분석 코드가 참값을 되찾는가** |
| `tests/test_metals.py` | **차단형과 손상형이 실제로 갈리는가** |

`test_hh.py` 가 존재하는 이유는 [`../결정기록.md`](../결정기록.md) 「정정」에 있다 —
속도상수 계수에서 10배를 놓쳤는데, **증상이 「정지전위가 −54 mV」 하나뿐이라
눈으로는 알 수 없었다.**

## 규칙

- **노트북에 계산을 쓰지 마라.** 노트북은 운전대, 계산은 `src/`
- **파생 데이터를 저장하지 마라.** 코드로 재생성한다
- 상수에는 출처를 주석으로 단다. **출처가 없으면 「없다」고 쓴다**
- 문서의 표를 손으로 고치지 마라. `sweep.py` 를 고쳐 다시 뽑는다
