## 지금 열린 것

### A. 코드가 없다 — 처음부터 직접 짠다 ★

**2026-08-24에 AI가 짠 시뮬레이터를 전부 지웠다.**
설계 문서(어떤 식을 어떤 구조로 놓을 것인가)는 남아 있으므로 **처음부터 다시는 아니다.**

**직접 짜는 것이 이 캠프의 목적이기도 하다** — 심사에서
"이 부분은 어떻게 되나요"에 답할 수 있어야 하고, 그건 남이 짠 코드로는 안 된다.
NEURON·Brian2를 기각한 이유와 같다 → [`결정기록.md`](결정기록.md).

**순서**: `hh.py`(막 한 조각) → `axon.py`(케이블) → `recording.py`(전극이 보는 것) → `metals.py`.
**막을 먼저 시험으로 못박고 가라** — 교과서 정상상태값(−65 mV에서 m·h·n)과 대조하는 시험이
없으면 속도상수의 계수 실수를 눈으로 못 잡는다.

### B. 분담이 안 정해졌다 — 이서율과 정할 것

**제안**(신이안이 정할 것):

| | 신이안 | 이서율 |
|---|---|---|
| 맡는 것 | 축삭·파형·수치해법 | 금속·용량반응 · 문헌 |
| 근거 | STSY 에서 측정장치 담당 | STSY 에서 지렁이·완화물질 담당 |

지표와 보고서는 둘이 같이.
**금속 상수를 훑는 일이 이서율 쪽 몫으로 자연스럽다** — STSY 에서 이미 물질을 다루기 때문이다.

### C. 수초 파라미터가 셋 다 없다

| 필요한 값 | 상태 |
|---|---|
| 등쪽 결절 간격 | **미확보.** Günther 1976 에 있을 것으로 보인다 |
| 수초 겹수 | 20–200 겹 (범위만 있다 · 원문 미확보) |
| 결절의 통로 밀도 | **미확보** |

**판단**: 셋 다 못 구할 가능성이 높다. Günther 1976 은 유료이고 STSY 쪽에서도 아직 못 받았다.

→ **구하려고 기다리지 말고 훑어라.** 결절 간격을 넓게 훑어 MGF 범위(15–45 m/s)에 드는
구간을 찾고, **그 구간 전체에서** 지표를 계산한다.
"이 파라미터에서 이렇다"가 아니라 **"MGF 속도를 내는 모든 조합에서 이렇다"** 가
오히려 더 강한 주장이다.

### D. 철의 근거가 한 층 더 얇다

납은 사람 직업노출 자료라도 있다(그것도 논문 특정 안 됨).
**철은 「철 노출 → 축삭 전도속도」 문헌을 하나도 확인하지 못했다.**

**판단**: 철은 흔한 토양 오염물이 아니라 **흔한 토양 성분**이다.
그래서 애초에 「중금속 오염」 문헌군에 안 들어 있을 가능성이 있다.
검색을 **「철 과부하 신경학」** 쪽으로 돌려야 할 수 있다
→ [`문헌/철_문헌군.md`](문헌/철_문헌군.md).

**없으면 없다고 쓴다.** 신규성이 되기도 한다 — 다만 그 경우
**모델의 철 부분이 순수 가설이라는 것을 보고서 앞쪽에 명시해야 한다.**

### E. 성능 — 단계 3이 코랩에서 끊길 수 있다

개체 여러 마리 몬테카를로는 무거워서 코랩 무료 세션에서 위험하다.

**대책은 구조에 있다** — **잡음을 축삭 안이 아니라 전극 단에서 더한다.**
기록 잡음은 물리적으로도 전극에서 섞이므로, 축삭을 다시 풀 필요 없이 파형에 더하면
**시행 50회가 축삭 계산 1회로 끝난다.** 단계 3에 들어갈 때 이 구조를 반드시 쓸 것.
