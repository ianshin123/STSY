## 멘토 제안 (2026-09-02) — **★ 신이안이 이 방향으로 간다고 정했다**

문자로 왔다. **이것이 방향의 정본이다.** 갈래별로 펼친 것은 [`방향.md`](%EB%B0%A9%ED%96%A5.md).

- 막전위 파형 모델은 실험과 잇기 어렵다 → **자극 역치와 전도속도**를 모델링한다
  (**신이안이 08-29 에 이미 같은 방향으로 바꿨다**)
- **Weiss–Lapicque 관계**로 자극 지속시간–역치를 수식화하고 **rheobase · chronaxie** 를 추정한다.
  선례로 **Bähring & Bauer 2014** 를 지목했다
- 역치 하나만 비교하지 말고 **여러 자극 지속시간에서 재서 r · c 가 어떻게 달라지는지** 본다
- 전도속도는 **「몇 % 느려진다」를 미리 정하지 말고, 농도와 노출시간에 따라 속도가 어떻게 변하는지
  모델을 추정**한다
- 중금속 효과는 **r · c · 전도속도가 각각 10 · 20 · 30 % 변한다는 시나리오**를 만들어
  측정 그래프가 어떻게 달라지는지 본다. 실측이 나오면 그 값으로 교체한다
- 정상 지렁이의 속도와 **측정오차를 가정**해, 효과가 **5 · 10 · 20 · 30 %** 일 때
  **몇 회 반복측정해야 잡히는지** 시뮬레이션한다
- 실험과 별개로 해야 한다면 **선행연구 값으로 정상 지렁이의 지속시간–역치 모델을 먼저** 만든다
- 또는 **가볍게 약소화**해도 된다

**보낸 참고문헌 3편의 서지를 확정했다** → 아래 「확인한 사실」.

## 확인한 사실 — 원문에서 (2026-09-02)

### Weiss–Lapicque 는 직선 하나로 끝난다

**a = 자극 진폭 · t = 자극 지속시간 · r = rheobase · c = chronaxie · q = a × t**

| | 식 |
|---|---|
| Lapicque | **a = r + (r·c)/t** (쌍곡선) |
| **Weiss** | **q = r·(t + c)** — **직선.** 기울기 = r · x절편 = −c |

**chronaxie 는 a = 2r 이 되는 t 다.**

**Bähring 자신의 데이터에서 직선(Weiss) 적합이 쌍곡선 직접 적합보다 유의하게 낫다**
(R² **0.9872 ± 0.0020** 대 **0.9434 ± 0.0077**, n = 64, P < 0.0001).
원문이 «theoretically, **only two good measurements** would be necessary to determine r and c» 라고 쓴다.

**정본과 Table 1 의 수치는
[`../문헌/Bahring2014_비마취챔버.md`](../%EB%AC%B8%ED%97%8C/Bahring2014_%EB%B9%84%EB%A7%88%EC%B7%A8%EC%B1%94%EB%B2%84.md) 에 있다.**
그 논문의 **예제 데이터 5종**(`threshold_biopac.acq` · `Chronaxie_biopac.acq` ·
`Conduction_velocity_biopac.acq` 등)도 저장소에 있다 →
[`../문헌/원문/Bahring2014_보조자료/`](../%EB%AC%B8%ED%97%8C/%EC%9B%90%EB%AC%B8/Bahring2014_%EB%B3%B4%EC%A1%B0%EC%9E%90%EB%A3%8C/).

### 멘토가 보낸 나머지 두 편

| 문헌 | 무엇 |
|---|---|
| [`OGara2004`](../%EB%AC%B8%ED%97%8C/OGara2004_%EA%B5%AC%EB%A6%AC%EC%A0%84%EB%8F%84%EC%86%8D%EB%8F%84.md) | 구리 **농도 × 노출시간 → 거대섬유 전도속도**를 실측한 논문. **2026-09-02 신이안이 원문을 구해 왔다.** 전도속도 축의 유일한 정량 선례 |
| [`Schwartz1988`](../%EB%AC%B8%ED%97%8C/Schwartz1988_%EB%82%A9%EC%A0%84%EB%8F%84%EC%86%8D%EB%8F%84%EC%97%AD%EC%B9%98.md) | 납 노출 어린이의 **용량–반응 역치**. **자극 역치가 아니다.** 저자들이 「전도속도는 저농도 납에 둔감한 검사」라고 쓴다 |

### 모델에 넣을 수 있는 값이 이미 있는 것 / 없는 것

| 축 | 있는 것 | 없는 것 |
|---|---|---|
| **정상 지렁이의 역치** | Bähring Table 1 — r **1.012 ± 0.052 V**(범위 0.4–2.5) · c **0.060 ± 0.005 ms**(범위 0.02–0.3) · n = 64 **시행** | **중금속이 r · c 를 얼마나 바꾸는지 잰 문헌이 하나도 없다** |
| **정상 지렁이의 속도** | Bähring **30.2 m/s**(비마취) · Shannon 22.8 · Yoshida 15.6 · 문헌 범위 15–45 | — |
| **금속 → 속도** | O'Gara: 구리 0.2 µM 24시간에 **초기값의 78 %(MGF)**. **약 25 %가 천장이고 넘기면 죽는다** | 카드뮴·납·아연에 대한 값. **카드뮴은 오히려 「안 바꾼다」는 인용이 있다** |
| **측정오차 σ** | **없다** — 아래 |

### ★ 검출력 시뮬레이션의 분모가 비어 있다

「효과 5 · 10 · 20 · 30 %를 잡으려면 몇 회 반복해야 하나」는 **반복측정 SD 가 있어야** 나온다.
**우리가 가진 SD 는 전부 개체 간이거나 시점 간이다** — 목록과 근거는
[`기록.md`](../%EA%B8%B0%EB%A1%9D.md) 4-4-2 절에 있다.

**그래서 다음 회차에 같은 자리에서 Δt 를 10회 반복해 우리 값을 재기로 했다**
(2026-09-02 · 신이안) → [`기록.md`](../%EA%B8%B0%EB%A1%9D.md) 목표 ③.

**가장 가까운 대용값**: O'Gara Fig. 4 대조군의 「초기값 대비 %」 오차막대 ≈ ±4.5 %(SEM, n = 10)
→ SD ≈ **14 %**. 군마다 6.6 – 21 %로 벌어진다.
**본문에 숫자로 없고 그림에서 눈으로 읽은 값이며, 종도 장치도 우리와 다르다.**
