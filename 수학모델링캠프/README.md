## 이 프로젝트의 주장 세 줄

1. **금속마다 모델 구조를 다르게 놓는다.** 같은 식에 계수만 바꾸면
   "셋이 다르게 나왔다"가 발견이 아니라 우리가 넣은 것이 된다
   → [`정리/금속별_기전.md`](정리/금속별_기전.md)
2. **속도 하나로는 원인을 못 가린다. 진폭을 같이 본다.**
   `S = 진폭 변화 ÷ 속도 변화` 가 차단형(납·카드뮴)과 손상형(철)과 온도를 가른다
   → [`정리/파형에서_지표까지.md`](정리/파형에서_지표까지.md)
3. **절대값을 예측하지 않는다.** 상수가 오징어 값이라 절대 속도는 지렁이의 값이 아니다.
   예측하는 것은 **변화의 모양과 비율**뿐이다 → [`정리/축삭모델_선택.md`](정리/축삭모델_선택.md)

## 경계

**이 프로젝트는 모델이고, STSY 는 실험이다. 둘은 별개의 산출물이다.**

- **모델의 예측을 실험 결과처럼 쓰지 않는다**
- **모델의 상수는 전부 우리 가정이다. 인용해서는 안 된다**
- **모델이 STSY 의 프로토콜을 바꾸라고 요구할 수 없다.** 제안은 [`../현재.md`](../현재.md)로 올리고
  신이안이 정한다
- 노출 농도 · 노출 방식 · 완화 물질은 여전히 STSY 팀원 몫이다 ([`../팀.md`](../팀.md))
