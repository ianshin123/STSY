## 나온 결론 셋

### 1. 무수 축삭으로는 MGF 속도가 안 나온다

가장 유리한 조건을 줘도 **7.48 m/s** — 문헌 MGF 범위 15–45 m/s 의 하한의 절반이다.
15 m/s 에 닿으려면 지름이 280 µm 여야 하는데 실측 MGF 는 70 µm 다.

**수초는 선택이 아니라 필수다.**
Günther(1976)가 전자현미경과 전기생리로 보인 것을,
우리는 계산이라는 **완전히 다른 방향**에서 같은 결론에 도달했다.

→ [`정리/축삭모델_선택.md`](정리/축삭모델_선택.md)

### 2. 전도속도 Q₁₀ 은 1.34 — 약 3 %/°C

STSY 가 들고 있는 **약 7 %/°C** 는 van't Hoff 어림값이고,
저장소 자신이 「상한에 가까운 어림값」이라고 단서를 달아 두었다.

**게이팅 Q₁₀ = 3 을 넣고 전도속도를 재면 Q₁₀ 이 1.34 로 줄어든다.**
속도가 속도상수에 선형으로 붙지 않기 때문이다.

실무 결론은 안 바뀐다(온도가 최대 교란변수다).
**바뀌는 것은 허용 폭이다** — 0.43 °C 를 지키는 것과 1.0 °C 를 지키는 것은 난이도가 다르다.

→ [`정리/온도와_Q10.md`](정리/온도와_Q10.md)

### 3. 진폭을 같이 보면 원인이 갈린다 ★ 산출물

전도속도 하나로는 납·카드뮴·철·온도를 구별할 수 없다.
그런데 넷은 **속도와 진폭을 다른 비율로** 움직인다.

```
S = 진폭 변화 % ÷ 속도 변화 %

  납        카드뮴      온도         철
 ─────────┼─────────┼───────────┼──────────
  S < 0    S ≈ 0     0.25~0.65    S > 1
```

**S 는 임의로 만든 지표가 아니라 기전이 파형에 남긴 자국이다.**
납은 게이팅 이동이 커서 전류원이 전극 아래 오래 머물러 진폭이 오히려 늘고,
철은 막이 새서 진폭이 속도보다 더 떨어진다.

**한계는 반드시 같이 읽을 것** — 카드뮴과 온도가 가장 가깝고,
진폭은 속도보다 재기 어려우며, 전부 무수 모델의 값이다.

→ [`정리/파형에서_지표까지.md`](정리/파형에서_지표까지.md)
