# 모델 설계 — 질문 · 가정 · 변수 · 검증

STSY 저장소의 [`../연구설계.md`](../연구설계.md)에 대응하는 문서다.
**실험이 아니라 모델이므로, 「교란변수 통제」 자리에 「가정과 그 검증」이 들어간다.**

---

## 연구 질문

> 지렁이 거대신경섬유의 전도속도가 떨어졌을 때,
> **파형에서 잴 수 있는 양만으로 그 원인이 어느 금속인지 — 혹은 그냥 온도인지 — 를
> 가려낼 수 있는가?**

실험이 답할 수 없는 질문이다. 실험은 원인을 이미 안 채로 결과를 보기 때문이다.
**모델은 원인을 넣고 결과를 보므로, 그 대응을 뒤집어 볼 수 있다.**

---

## 가설

| 기호 | 내용 | 상태 |
|---|---|---|
| M₁ | 납·카드뮴(차단형)과 철(손상형)은 **서로 다른 파형 지문**을 남긴다 | **단계 1에서 지지됨** |
| M₂ | 그 지문은 **온도가 만드는 변화와도 구별된다** | **단계 1에서 지지됨** |
| M₃ | 차단형은 시간에 평평하고 손상형은 시간에 자란다 | **단계 1에서 지지됨** (구조상 당연 — 아래 주의) |
| M₄ | 지문 구조는 **수초를 얹어도 유지된다** | **미검증 — 단계 2** |
| M₅ | 실측 잡음 수준에서도 지문이 살아남는다 | **미검증 — 단계 3** |

> ### ★ M₃ 에 대한 주의 — 순환논증을 피할 것
>
> "차단형은 시간에 평평하다"는 **우리가 그렇게 모델링했기 때문에** 나온다.
> 모델이 발견한 것이 아니다.
>
> **모델이 실제로 한 일은 「그 구조 차이가 관측 가능한 크기로 나타나는가」를
> 확인한 것**이다. 구조를 다르게 놓아도 효과가 잡음에 묻히면 실험으로는
> 구별할 수 없기 때문이다.
>
> 이 구분을 보고서에서 흐리면 안 된다.
> M₁ · M₂ 도 같은 성격이 일부 있다 — 다만 S 의 **부호와 크기**는
> 구조에서 자명하게 따라 나오지 않았고, 우리도 미리 예측하지 못했다.

## 변수

| 구분 | 변수 | 어떻게 다루는가 |
|---|---|---|
| **독립** | 금속 종류 | 납 · 카드뮴 · 철. 각각 다른 모델 구조 |
| | 농도 | **반효과농도의 배수**로만. 절대 농도는 모델에 없다 |
| | 노출 일수 | 0 · 1 · 2 · 4 · 7 (STSY 설계와 같게) |
| | 온도 | 게이팅 속도상수의 계수 `phi(T)` |
| **종속** | 전도속도 | 참값(막전위 정점) · 추정값(세포외 파형 + 분석 코드) 둘 다 |
| | 진폭 | 이극 채널의 peak-to-peak |
| | **지표 S** | 진폭 변화 ÷ 속도 변화 ← **산출물** |
| | 전파 여부 | 발화 확률의 기초 (단계 4) |
| **훑는 것** | 지름 · 세로저항 · 세포외 전도도 · 전극 깊이 | **실측값이 없다.** 값을 주장하지 않고 범위를 훑는다 |

## 가정과 그 검증 ★

교란변수 대신 이 표가 이 문서의 중심이다.
**가정을 적어 두지 않으면, 결과가 나왔을 때 그것이 무엇의 결과인지 알 수 없다.**

| 가정 | 왜 위험한가 | 어떻게 다루는가 |
|---|---|---|
| **HH 오징어 상수를 쓴다** | 지렁이 통로가 아니다. 절대값이 틀린다 | **절대값을 예측하지 않는다.** 상대 변화만 본다 → [`정리/축삭모델_선택.md`](정리/축삭모델_선택.md) |
| **무수 축삭이다** | 지렁이 MGF 는 수초가 있다 (Günther 1976) | 단계 2에서 얹는다. 그때 지표를 재산출한다 |
| **금속 상수가 전부 우리 값이다** | S 의 절대값이 가정에 의존한다 | 훑는다. **부호가 유지되는 범위**를 보고한다 → [`정리/금속별_기전.md`](정리/금속별_기전.md) |
| **철 → 누설 증가** | **문헌 근거가 없다.** 가장 약한 고리 | 가설로 명시한다. 실험이 이것을 검증한다 |
| **세포외 매질이 무한 균질** | 체벽·체강액이 층을 이룬다 | 절대 진폭을 믿지 않는다. **변화율만** 쓴다 |
| **막 파라미터가 축삭 전체에 균일** | 실제 손상은 얼룩덜룩하다 | 단계 4의 과제. 지금은 못 한다 |
| **자극 시점이 정확하다** | 실험은 기계적 자극이라 지터가 있다 | 우리도 **두 채널의 상대 지연만** 쓴다 (STSY 와 같은 대응) |

## 검증 전략 — 세 층

모델은 실험처럼 「참값」과 대조할 수 없다. 대신 세 방향에서 조인다.

### 1. 해석적 결과와 대조 (코드가 맞는가)

- `v ∝ sqrt(d / R_a)` — 무수 케이블 이론. **지름 4배 → 속도 2배로 재현됨**
- 정상상태 m·h·n 이 교과서값과 일치
- dx 를 반으로 줄여도 속도가 1 % 안에서 안 변함 (공간 수렴)

→ [`코드/tests/test_axon.py`](코드/tests/test_axon.py)

### 2. 문헌 수치와 대조 (물리가 맞는가)

| 양 | 문헌 | 모델 |
|---|---|---|
| 세포외 진폭 | MGF 29.4 µV (Yoshida 2009 Fig. 8 · 원문 확인) | 92 µV — **자릿수는 맞고 3배 크다** |
| MGF 속도 | 15–45 m/s | 4.4 m/s — **못 닿는다. 수초가 필요하다는 결론** |
| 온도 계수 | 약 7 %/°C (van't Hoff 어림값) | **약 3 %/°C** → [`정리/온도와_Q10.md`](정리/온도와_Q10.md) |

**진폭이 3배 큰 것은 무한 균질 매질 가정 때문으로 본다**(우리 판단).
실제 체벽은 전류를 가두지 않고 흩는다.

### 3. 저장소의 분석 코드와 대조 (파이프라인이 맞는가)

시뮬레이션 파형을 [`../분석/src/velocity.py`](../분석/src/velocity.py)에 넣어
참값을 되찾는지 본다. **오차 0.028 %** → [`정리/파형에서_지표까지.md`](정리/파형에서_지표까지.md)

## 이 모델이 답하지 않는 것

- **실제 노출 농도에서 몇 %가 떨어지는가** — 상수가 없다
- **어느 금속이 더 위험한가** — 우리가 넣은 상수가 그 답을 결정한다
- **완화 물질** — 범위 밖
- **지렁이 개체가 죽는가 · 행동이 변하는가** — 축삭 하나만 본다
