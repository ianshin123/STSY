## 지금 근거로 쓰고 있는 것

### 확립 — 화학

```
Fe²⁺ + H₂O₂  →  Fe³⁺ + OH⁻ + ·OH        (펜톤 반응)
```

하이드록실 라디칼이 막 지질을 산화시킨다(지질 과산화).
**표준 화학이고 교과서 수준이다.** 다만 우리는 1차 문헌을 열지 않았다.

### 확립 — 생물학적 지위

철은 **필수 영양소**다. 부족해도 나쁘고 과해도 나쁘다.
납·카드뮴에는 없는 성질이고, 그래서 용량–반응이 U자가 될 수 있다.

지렁이는 체액에 헤모글로빈(에리트로크루오린)을 갖는다
— **확인 필요. 인용 전에 1차 문헌을 열 것.**

### 우리 가설 — 여기가 구멍이다 ★

**「지질 과산화 → 축삭 누설 전도도 증가」는 문헌이 아니라 우리 가설이다.**

과산화된 막의 투과성이 올라간다는 것은 알려져 있지만,
그것이 **지렁이 MGF 축삭에서 g_L 을 몇 배 올리는지**는 아무도 재지 않았다.

## 확보하지 못한 것

| 필요한 것 | 상태 |
|---|---|
| 철 노출과 **축삭 전도속도**의 직접 관계 | **없다.** 사람·쥐에서도 못 찾았다 |
| 지렁이의 철 독성 역치 | **없다** |
| 지렁이 철 항상성 (저장·배출) | **없다.** U자의 왼쪽 가지를 판정할 근거가 없다 |
| 지질 과산화 → 막 전도도의 정량 관계 | **없다** |

**철은 납·카드뮴보다 근거가 한 층 더 얇다.**
납은 사람 직업노출 자료라도 있지만(그것도 논문 특정 안 됨),
철은 그 수준의 자료조차 확인하지 못했다.

## 해야 할 일 ★

1. **철 노출과 신경전도의 관계**를 다룬 논문이 존재하는지부터 확인한다.
   없으면 **「없다」고 보고서에 쓴다.** 그것도 결과다
2. **지렁이 철 독성** 문헌 — 생태독성학 쪽에 있을 가능성이 높다
   (철은 흔한 토양 오염물이 아니라 오히려 흔한 토양 성분이다.
   **그래서 애초에 「중금속 오염」 문헌군에 안 들어 있을 수 있다** — 이 점을 먼저 확인)
3. **지질 과산화 → 막 전기적 성질** 논문을 특정
4. 지렁이 헤모글로빈(에리트로크루오린)의 1차 문헌 확인

검색어 후보: `iron neurotoxicity nerve conduction`,
`Fenton reaction lipid peroxidation membrane conductance`,
`earthworm iron toxicity Eisenia`, `Lumbricus erythrocruorin`

무료 경로 확인 순서는 [`../../CLAUDE.md`](../../CLAUDE.md) 인용 규칙에 있다 —
