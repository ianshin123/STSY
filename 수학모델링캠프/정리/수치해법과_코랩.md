## 함정 1 — 화면 가득 nan ★

명시적 오일러는 `dt` 가 어떤 값을 넘으면 **발산한다.** 조용히 틀리는 게 아니라
숫자가 전부 nan 이 되는데, 처음 보면 원인을 찾기 어렵다.

가장 빠른 시간상수는 **축방향 결합**에서 온다.
이산 라플라시안의 고유값이 [−4, 0] 이므로:

```
dt < 2 / ( (4 * g_ax + g_ion) / c_m )       g_ax = 1000 d / (4 R_a dx²)
```

지름 70 µm · dx 100 µm · R_a 100 Ω·cm 이면 `g_ax = 175 mS/cm²` 이고
**한계는 약 0.00093 ms (0.93 µs)** 다.

[`../코드/src/axon.py`](../코드/src/axon.py) `max_stable_dt()` 가 이 값을 계산하고,
넘는 `dt` 를 주면 **nan 대신 설명이 있는 오류**를 낸다.

### 느리면 dt 를 줄이지 말고 dx 를 키워라

`g_ax` 가 `1/dx²` 이라, **dx 를 키우면 dt 한계가 크게 완화된다.**
dx 를 2배 하면 한계는 약 2.6배 늘어난다
(정확히 4배가 아닌 것은 이온 전도도 항이 dx 에 무관하기 때문이다).

**dx 를 얼마까지 키워도 되는가**: 스파이크의 공간 폭보다 훨씬 작으면 된다.
4.4 m/s 에서 상승기가 약 0.3 ms 면 공간 폭이 약 1.3 mm 다.
dx = 100 µm 는 그 안에 13점이 들어가는 셈이라 충분하다 —
**dx 를 50 µm 로 줄여도 속도가 0.6 % 밖에 안 변한다**
([`../코드/tests/test_axon.py`](../코드/tests/test_axon.py) `test_dx를_줄여도_속도가_안_바뀐다`).

**이 확인을 먼저 하지 않으면, 나중에 나오는 모든 결론이 물리인지 이산화 오차인지
구별할 수 없다.**

## 함정 2 — 파이썬 for 문의 속도

시간 스텝은 순차적이라 for 문을 피할 수 없다.
**피할 수 있는 것은 공간 방향의 for 문이다.**

```python
for i in range(n):                     # 느리다 — 구획마다 파이썬 호출
    lap[i] = v[i-1] - 2*v[i] + v[i+1]

lap[1:-1] = v[:-2] - 2*v[1:-1] + v[2:]  # 빠르다 — numpy 한 번
```

600구획 × 6000스텝이 **약 1초**다. 공간을 for 문으로 돌면 수십 배 느려진다.

### 대량 계산의 크기 감각

| 하는 일 | 실행 횟수 | 대략 시간 |
|---|---|---|
| 한 조건 | 1 | 1–2 초 |
| 금속 3 × 농도 4 × 시점 5 | 60 | 약 2 분 |
| 거기에 개체 20마리 (단계 3) | 1200 | **약 40 분** |

**단계 3의 몬테카를로는 코랩에서 세션이 끊길 수 있는 길이다.**
대책 둘:
- **잡음은 축삭 안이 아니라 전극에서 더한다.** 기록 잡음은 물리적으로도
  전극 단에서 섞이므로, 축삭을 다시 풀 필요 없이 파형에 더하면 된다
  ([`../코드/src/recording.py`](../코드/src/recording.py) `add_noise`).
  시행 50회가 축삭 1회 계산으로 끝난다
- 결과를 중간중간 저장한다

### 노트북에 계산을 쓰지 마라

**노트북은 얇은 운전대이고, 계산은 전부 `src/` 의 `.py` 에 둔다.** 이유:

- 노트북은 git diff 가 안 읽힌다. 뭐가 바뀌었는지 알 수 없다
- 시험을 붙일 수 없다
- 셀을 순서대로 안 돌리면 결과가 달라진다

## 단위 — 섞으면 조용히 틀린다

| 양 | 단위 |
|---|---|
| 전압 V | mV |
| 시간 t | ms |
| 막용량 C | µF/cm² |
| 전도도 g | mS/cm² |
| 전류밀도 I | µA/cm² |
| 길이 · 지름 | cm (입력은 µm · mm 로 받고 안에서 변환) |
| 세로저항 R_a | Ω·cm |
| 세포외 전도도 σ | S/cm |
| 세포외 전위 φ | **µV** |

`g_ax` 의 1000 은 S/cm² → mS/cm² 환산이다.

**세포외 전위가 µV 로 저절로 나오는 것이 편리하다** —
`i_m·A [µA] / (σ [S/cm] · r [cm]) = µA/S = µV`.
문헌의 표면 신호가 20–100 µV 급이라 자릿수를 바로 대조할 수 있다.
