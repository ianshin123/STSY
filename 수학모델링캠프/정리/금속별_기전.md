# 금속 셋을 어떻게 다르게 놓는가

**이 노트가 이 프로젝트의 핵심 주장이다.**

납 · 카드뮴 · 철에 **같은 식을 주고 계수만 바꾸면 안 된다.**
그렇게 하면 "세 금속이 다르게 나왔다"는 결과가 나와도 그것은
우리가 계수를 다르게 넣었기 때문이지 발견이 아니다.

세 금속은 **작용하는 자리가 다르다.** 그래서 모델 구조 자체를 다르게 놓는다.
구현은 신이안·이서율이 직접 세운다.

---

## 근거의 층위 ★ 먼저 읽을 것

이 노트에는 세 종류의 문장이 섞여 있다. 반드시 구별해서 읽어야 한다.

| 층위 | 무엇 | 이 노트에서의 표시 |
|---|---|---|
| **확립** | 교과서·1차 문헌이 지지하는 물리화학 | 출처를 적는다 |
| **이전 가정** | 그 기전이 지렁이 축삭에도 적용되는가 | **「이전 가정」** 이라고 쓴다 |
| **우리 구조** | 그것을 어떤 수식·상수로 놓을 것인가 | **「우리 구조」** 라고 쓴다 |

**이 모델의 상수 중 문헌에서 온 것은 하나도 없다.**
전부 훑어야 하는 미지수이고, 인용해서는 안 되는 값이다.

STSY 저장소가 「수초 철회 사건」에서 값을 치른 규칙이 여기에도 그대로 적용된다 —
**기전을 다른 종으로 옮길 때는 이전 가능성을 따로 논증한다**
([`../../결정기록.md`](../../결정기록.md) 「철회된 주장」).

## 두 갈래로 나뉜다 — 차단형과 손상형

```
                    ┌── 차단형 (납 · 카드뮴) ────────────────┐
2가 양이온이          │  통로 단백질에 붙는다                  │
막에 도달             │  · 막 표면 음전하를 가린다 -> 게이팅 이동 │
   │                │  · 구멍 자체를 막는다      -> g_Na 감소   │
   │                │                                       │
   ├───────────────▶│  농도에 즉시 평형 · 시간에 거의 무관     │
   │                │  노출을 끊으면 되돌아간다               │
   │                └───────────────────────────────────────┘
   │
   │                ┌── 손상형 (철) ────────────────────────┐
   │                │  펜톤 반응으로 라디칼을 만든다           │
   └───────────────▶│  · 막 지질을 산화시킨다 -> 누설 증가     │
                    │                                       │
                    │  농도 x 시간으로 쌓인다                 │
                    │  노출을 끊어도 되돌아가지 않는다         │
                    └───────────────────────────────────────┘
```

**이 구조 차이가 관측 가능한 지문 차이로 나온다.** 그것이 이 프로젝트의 산출물이다
→ [`파형에서_지표까지.md`](파형에서_지표까지.md).

## 차단형 — 납과 카드뮴

### 확립: 2가 양이온의 표면전하 효과

세포막 바깥면에는 음전하가 깔려 있다(인지질 머리기, 당사슬).
2가 양이온이 여기 붙어 음전하를 가리면, **통로 단백질이 느끼는 전압이
실제 막전위보다 과분극된 쪽으로 치우친다.**

결과: **활성화 곡선 전체가 탈분극 쪽으로 밀린다.** 같은 전압에서 통로가 덜 열린다.

칼슘으로 이 현상이 보고돼 있다
(Frankenhaeuser & Hodgkin 1957, *J Physiol* 137:218–244 · **원문 미확보**).

**구현**: 속도상수 `alpha`, `beta` 의 전압 인자에서 `shift_mv` 를 뺀다.
막 파라미터 한 개만 바뀌고 나머지는 그대로다 —
속도상수의 전압 인자에서만 바꾸면 되고 나머지는 그대로다.

### 확립: 구멍 차단

카드뮴은 전기생리 실험에서 **표준 Ca²⁺ 통로 차단제로 쓰인다**
(실험 관행 · **문헌 특정 안 됨**).
납은 Ca²⁺ 를 흉내내 칼슘 통로를 차단한다
([`../../문헌/납신경독성_문헌군.md`](../../문헌/납신경독성_문헌군.md) · **논문 특정 안 됨**).

**구현**: `na_scale` 로 g_Na 를 깎는다.

### 이전 가정: 지렁이 축삭에도 통하는가

**통할 가능성이 높다.** 근거는 STSY 저장소의 판단을 그대로 가져온다 —
전압의존성 통로는 동물 전반에 보존돼 있고, 2가 양이온의 결합은
선택성 필터의 일반적인 물리화학적 상호작용이라 종 특이성이 낮다
([`../../정리/중금속_신경독성.md`](../../정리/중금속_신경독성.md)).

**단, 이것은 문헌이 검증한 것이 아니라 우리 추론이다.**

### 우리 구조: 농도를 파라미터로 옮기는 식

```
theta(C) = C^h / (C^h + K^h)          점유율 (Langmuir / Hill)
shift    = shift_max * theta
g_Na     = g_Na0 * (1 - (1 - na_min) * theta)
```

시간이 들어가지 않는다. 결합·해리가 하루보다 훨씬 빠르다고 보기 때문이다
(**우리 가정**. 체내 축적 동역학은 별개 문제이고 우리는 그것을 다루지 않는다).

| 상수 | 값 | 근거 |
|---|---|---|
| `shift_max_mv` | 납 15 · 카드뮴 8 | **없다.** 훑을 대상 |
| `na_block_max` | 납 0.85 · 카드뮴 0.70 | **없다.** 카드뮴이 구멍 차단에 더 강하다는 대비 자체가 가설 |
| `k_half` | 납 1.0 · 카드뮴 1.5 | **없다.** 농도 단위조차 팀이 정하기 전이다 |

**절대 농도를 모르므로 이 모델은 「반효과농도의 몇 배인가」로만 말한다.**
팀이 실제 노출 농도를 정하면, 필요한 것은 `k_half` 하나뿐이다.

## 손상형 — 철

### 왜 다른 칸에 놓는가

**철이 납·카드뮴과 다른 다섯 가지(필수 영양소 · 펜톤 반응 · U자 용량–반응 ·
농도×시간 누적 · 비가역)와 펜톤 반응식은
[`../../정리/중금속_신경독성.md`](../../정리/중금속_신경독성.md) 「철은 앞의 둘과 같은 칸에
놓을 수 없다」에 있다.** 여기서는 그것을 **어떤 식으로 놓을 것인가**만 다룬다.

### 이전 가정 ★ 여기가 가장 약하다

**「지질 과산화 → 축삭 누설 전도도 증가」는 문헌이 아니라 우리 가설이다.**

과산화된 막의 투과성이 올라간다는 것은 알려져 있지만,
그것이 **지렁이 MGF 축삭에서 얼마만큼의 g_L 증가로 나타나는지**는
누구도 재지 않았다. 우리는 그 연결을 **가정하고** 모델에 넣는다.

**보고서에 이렇게 써야 한다** — "철을 산화 손상 경로로 모델링했다"가 아니라
**"철을 산화 손상 경로로 모델링하면 이런 지문이 나오고, 실험에서 그 지문이
보이는지로 이 가정을 검증할 수 있다."**

### 우리 구조: 시간이 들어간다

```
D(C, t) = 1 - exp(-k * C * t)          누적 손상 (회복항 없음)
g_L     = g_L0 * (1 + (leak_max - 1) * D)
```

`C * t` 로 들어간다는 것이 핵심이다 —
**농도 2로 1일 노출과 농도 1로 2일 노출이 같은 손상을 준다.**
차단형에는 이 성질이 없다.

| 상수 | 값 | 근거 |
|---|---|---|
| `leak_max` | 6.0 | **없다** |
| `k_damage` | 0.25 | **없다** |
| `shift_max_mv` | 2.0 | **없다.** 철도 2가 양이온이라 표면전하 효과가 0은 아닐 것이라는 우리 판단 |

### U자 곡선 — 모델은 알지만 실험은 못 볼 것이다

철은 부족해도 나쁘고 과해도 나쁘다.
모델이 이것을 그릴 수 있다.

**그런데 왼쪽 가지(결핍)는 우리 실험에서 만들어지지 않을 가능성이 높다.**
노출 실험은 흙에 이미 있는 철에 **더 얹는** 것이고,
7일은 저장 철을 고갈시키기에 짧다.

→ **예측에 쓰는 것은 오른쪽 가지뿐이다.** U자는 "모델이 필수 원소를
비필수 금속과 구별해서 다룬다"는 것을 보이는 용도다.
결핍 가지의 형태와 상수는 전부 우리 가정이고 문헌 근거가 없다.

## 이 구조가 만드는 예측 두 개

두 예측 모두 **실험으로 반증 가능하다.** 그게 이 모델의 값어치다.

### 예측 1 — 시간 경과가 갈린다

같은 농도로 0 · 1 · 2 · 4 · 7일을 추적하면,
**납·카드뮴은 첫날 이후 평평하고 철은 계속 자란다.**

### 예측 2 — 속도와 진폭의 결합이 갈린다

**차단형은 속도만 떨어뜨리고, 손상형은 속도와 진폭을 같이 떨어뜨린다.**

수치와 판별 지표는 [`파형에서_지표까지.md`](파형에서_지표까지.md)에.

### 예측이 빗나가는 경우 — 미리 적어 둔다

| 관측 | 뜻하는 것 |
|---|---|
| 셋 다 시간에 평평 | 철의 손상형 가정이 틀렸거나, 7일이 짧다 |
| 셋 다 시간에 자람 | 체내 축적 동역학이 지배한다 — 우리가 뺀 요소다 |
| 진폭이 아무 데서도 안 변함 | 우리 g_L 연결이 틀렸다 |
| 철에서 U자의 왼쪽이 보임 | 노출이 결핍을 만들었다는 뜻 — 설계를 다시 봐야 한다 |

**빗나가도 결과다.** 어느 가정이 틀렸는지를 좁혀 주기 때문이다.

## 이 노트가 다루지 않는 것

- **노출 농도 · 노출 방식** — STSY 팀원 몫이다 ([`../../팀.md`](../../팀.md))
- **체내 축적 동역학** — 피부 흡수 속도, 조직 분배. 확보하지 못했고 모델에 없다.
  모델의 「농도」는 **축삭이 실제로 느끼는 농도**이지 흙 속 농도가 아니다.
  이 둘 사이에 미지의 변환이 하나 더 있다
- **시냅스 전달** — Ca²⁺ 통로 차단의 가장 확립된 효과인데, 우리 축삭 모델에는
  Ca²⁺ 통로가 없다. 발화 확률을 이 경로로 다루려면 모델을 늘려야 한다
  → [`../로드맵.md`](../로드맵.md) 단계 4
