# 축삭을 어떤 모델로 놓는가

지렁이 MGF 를 컴퓨터 안에 세우는 방법은 여럿이다.
어느 것을 골랐고 **무엇을 포기했는지**를 적는다.

기각한 대안과 그 이유는 [`../결정기록.md`](../결정기록.md)에.

---

## 고른 것 — 호지킨–헉슬리 + 케이블 방정식

```
c_m dV_i/dt = -I_ion(V_i) + g_ax (V_{i-1} - 2V_i + V_{i+1}) + I_stim

g_ax = 1000 * d / (4 R_a dx^2)          [mS/cm²]
```

축삭을 길이 `dx` 짜리 원통 조각으로 썰고, 조각마다 HH 막을 붙이고,
이웃끼리 세로저항으로 잇는다.

**왜 이것인가:**
- 신이안이 이미 HH 를 손으로 풀어 본 적이 있다
  ([`../../정리/활동전위와_이온통로.md`](../../정리/활동전위와_이온통로.md)
  「신이안의 선행 작업과의 연결」). 같은 식을 이번에는 컴퓨터로 공간까지 늘린다
- **중금속이 들어올 자리가 명시적이다.** 통로 파라미터를 건드리는 것이
  곧 중금속 효과다 → [`금속별_기전.md`](금속별_기전.md)
- numpy 배열 연산만으로 구현된다. 특수 라이브러리가 필요 없다

### 수치해법 — 명시적 오일러, 그리고 그 함정

가장 빠른 시간상수는 **축방향 결합**에서 온다.
이산 라플라시안의 고유값이 [−4, 0] 이므로 안정 조건은

```
dt < 2 / ( (4 g_ax + g_ion) / c_m )
```

지름 70 µm · dx 100 µm · R_a 100 Ω·cm 이면 `g_ax ≈ 175 mS/cm²` 이고
**한계가 약 1 µs 다.** 넘으면 조용히 틀리는 게 아니라 **전부 nan 이 된다.**

**느리면 dt 를 줄이지 말고 dx 를 키워라.** `g_ax ∝ 1/dx²` 이라 dx 를 2배 하면
한계가 크게 완화된다. dx 는 **스파이크의 공간 폭보다 충분히 작기만 하면 된다** —
`공간 폭 ≈ 전도속도 × 상승기 지속시간`.

**공간 for 문을 쓰지 마라.** 시간 스텝은 순차적이라 피할 수 없지만,
공간은 numpy 슬라이스 한 줄이다 (`lap[1:-1] = v[:-2] - 2*v[1:-1] + v[2:]`).

**dx 수렴 확인을 먼저 하지 않으면, 나중에 나오는 모든 결론이
물리인지 이산화 오차인지 구별할 수 없다.**

---

## 파라미터가 없다는 문제 ★

**지렁이 MGF 의 HH 파라미터 실측값은 존재하지 않는다.**

우리가 쓰는 상수는 전부 **오징어 거대축삭 6.3 °C** 값이다
(Hodgkin & Huxley 1952 · **원문 미확보**). 오징어는:

- 무수신경이다 (지렁이 MGF 는 수초가 있다)
- 지름이 약 500 µm 다 (MGF 는 70 µm)
- 해수 온도에서 잰 값이다

**그러므로 이 모델이 내놓는 절대 속도값은 지렁이의 값이 아니다.**

> ### 이 모델이 예측하는 것과 예측하지 않는 것
>
> **예측하지 않는다** — "실측은 27.3 m/s 가 나올 것이다" 같은 절대값
>
> **예측한다** — 변화의 **모양**과 **비율**:
> 용량–반응 곡선의 형태, 시간 경과의 형태, 속도와 진폭이 같이 움직이는지,
> 온도와 금속이 구별되는지
>
> 절대값이 아니라 **상대 변화와 지문**을 예측하는 모델이다.
> 파라미터가 없어도 성립하고, 실험으로 반증도 된다.

---

## 예상되는 결론 하나 — 무수 모델은 MGF 속도에 못 닿는다

**손으로 먼저 따져 볼 수 있고, 그래서 코드 검증의 잣대가 된다.**

무수 케이블에서 `v ∝ √(d / R_a)` 다. 오징어 거대축삭은 지름 약 500 µm 에 약 20 m/s.
지렁이 MGF 는 **지름 약 70 µm** 인데 문헌 속도는 **15–45 m/s** 다.

```
√(70 / 500) = 0.37     →  같은 막·같은 R_a 라면 20 × 0.37 ≈ 7 m/s
```

**MGF 범위 하한(15 m/s)의 절반이다.** 15 m/s 에 닿으려면 지름이 4배 이상 필요하다.

> **따라서 무수 모델로는 지렁이 MGF 속도를 만들 수 없다. 수초는 선택이 아니라 필수다.**

**이것이 이 프로젝트가 문헌을 독립적으로 확인하는 지점이다.**
Günther(1976)가 등쪽 결절과 도약전도를 **전자현미경과 전기생리로** 보였는데(원문 미확보),
우리는 **계산이라는 다른 방향**에서 같은 결론에 닿는다.

**주의**: 이것은 「지렁이에 수초가 있다」의 증명이 아니다.
「무수 HH 케이블이 **이 파라미터로는** 그 속도를 못 낸다」의 증명이다.
다른 설명(우리가 모르는 통로 조성, 훨씬 낮은 세로저항)도 원리적으로 가능하다.

**시뮬레이션이 할 일은 이 어림 계산을 정밀화하는 것**이고,
숫자는 직접 세운 코드로 낸다.

## 온도가 들어오는 자리 ★ STSY 에 직접 쓰인다

온도는 게이팅 속도상수 `alpha`, `beta` 에 계수 하나로 들어간다.

```
phi(T) = Q10 ^ ((T - 6.3) / 10)        Q10 = 3 (HH 원논문 값 · 원문 미확보)
```

> ### 게이팅 Q₁₀ 과 전도속도 Q₁₀ 은 같지 않다
>
> **전도속도는 속도상수에 선형으로 붙지 않는다.**
> 케이블 이론에서 속도는 대략 제곱근 쪽으로 붙으므로,
> 게이팅 Q₁₀ 이 3이어도 **전도속도 Q₁₀ 은 √3 ≈ 1.7 이하**로 나온다.
> 온도가 오르면 활동전위가 짧아지고 진폭도 줄어 다음 구획을 역치까지 밀어올릴
> 전하가 줄기 때문에, **실제로는 그보다도 작을 것으로 본다**(우리 추론).

**이것이 STSY 에 직접 걸린다.** STSY 는 온도 계수로 van't Hoff 어림값
**약 7 %/°C** 를 들고 있는데, 그 값은 **생화학 반응 속도**의 규칙이지
축삭 전도속도의 실측값이 아니다
→ [`../../정리/전도속도_결정요인.md`](../../정리/전도속도_결정요인.md).

**모델이 이 구멍에 숫자를 낼 수 있다.** 단, 세 가지 단서가 붙는다:
① **무수 모델**의 값이다 — 지렁이 MGF 는 수초가 있다
② 게이팅 Q₁₀ = 3 은 **오징어 값**이다. 지렁이 통로의 Q₁₀ 은 아무도 재지 않았다
③ 세로저항 · 세포외 전도도 · 열팽창의 온도 의존이 모델에 없다

**그래도 Kladt 2010 Figure 12(실측 온도–속도 곡선) 확보가 여전히 최우선이다** —
모델이 낸 값을 검증할 유일한 대조군이기 때문이다.

## 이 모델이 담지 못하는 것

정직하게 적어 둔다. 심사에서 반드시 묻는다.

- **수초** — 단계 2. 위 참조
- **Ca²⁺ 통로** — HH 오징어 모델에 없다. 중금속의 가장 확립된 표적인데 빠져 있다
- **시냅스** — 거대섬유에서 운동뉴런으로 넘어가는 지점이 없다
- **전도 촉진(초정상성)** — Kladt 2010 이 3–20 ms 구간에서 실측한 현상(원문 확인).
  HH 는 이걸 자연스럽게 내지 않는다
- **체내 축적 동역학** — 모델의 「농도」는 축삭이 느끼는 농도이지 흙 속 농도가 아니다
- **개체차** — 지름·온도·전극 위치가 개체마다 다르다. 훑기로만 다룬다
