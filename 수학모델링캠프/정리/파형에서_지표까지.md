# 파형에서 지표까지 — 무엇을 재면 원인을 알 수 있는가

**이 노트가 이 프로젝트의 산출물이다.**

시뮬레이션이 파형을 만들고, 그 파형에서 지표를 뽑고,
그 지표가 **무엇이 전도속도를 떨어뜨렸는지** 를 가려낸다.

---

## 문제 — 전도속도 하나로는 원인을 못 가린다

전도속도가 좋은 지표인 이유는 여러 요인이 하나의 숫자로 모이기 때문이고,
**그것이 동시에 최대 약점이다**
([`../../정리/전도속도_결정요인.md`](../../정리/전도속도_결정요인.md)).

속도가 5 % 떨어졌다고 하자. 원인은:

- 납이 통로를 막았다
- 카드뮴이 통로를 막았다
- 철이 막을 손상시켰다
- **그냥 방이 1.7 °C 추웠다** ([`온도와_Q10.md`](온도와_Q10.md))

**속도 하나만 보면 이 넷을 구별할 방법이 없다.**

---

## 답 — 진폭을 같이 본다

시뮬레이션이 만드는 세포외 파형에서는 속도와 **진폭**을 둘 다 잴 수 있다.
그리고 네 요인은 이 둘을 **다른 비율로** 움직인다.

```
S = (진폭 변화 %) / (속도 변화 %)
```

기울기 하나다. 20 °C · 7일 노출 기준
([`../코드/src/sweep.py`](../코드/src/sweep.py) `table_slope`):

| 요인 | 속도 변화 | 진폭 변화 | 기울기 S |
|---|---|---|---|
| 납 · 농도 1.0 | −7.20 % | +2.73 % | **−0.378** |
| 납 · 농도 2.0 | −10.05 % | +2.95 % | **−0.294** |
| 카드뮴 · 농도 1.0 | −5.95 % | −0.16 % | **+0.027** |
| 카드뮴 · 농도 2.0 | −8.76 % | −0.71 % | **+0.081** |
| 온도 19 °C (−1) | −2.77 % | −1.43 % | **+0.515** |
| 온도 18 °C (−2) | −5.57 % | −3.13 % | **+0.562** |
| 온도 17 °C (−3) | −8.36 % | −5.06 % | **+0.606** |
| 온도 21 °C (+1) | +2.65 % | +1.09 % | **+0.412** |
| 온도 22 °C (+2) | +5.31 % | +1.80 % | **+0.340** |
| 온도 23 °C (+3) | +7.87 % | +2.08 % | **+0.264** |
| 철 · 농도 1.0 | −14.97 % | −18.62 % | **+1.244** |
| 철 · 농도 2.0 | −17.62 % | −20.43 % | **+1.160** |

> ### 네 요인이 S 하나로 갈린다
>
> ```
>   납        카드뮴      온도         철
>  ─────────┼─────────┼───────────┼──────────
>   S < 0    S ≈ 0     0.25~0.65    S > 1
> ```
>
> **진폭이 오히려 오르면 납, 진폭이 안 변하면 카드뮴,
> 진폭이 속도보다 더 떨어지면 철.**

### 왜 이렇게 갈리는가 — 기전이 그대로 드러난다

| 요인 | 무엇이 일어나는가 | 왜 그 기울기인가 |
|---|---|---|
| **납** | 게이팅 이동이 크다 (15 mV) | 전파가 느려지면 전류원이 전극 아래 **오래 머문다** → 진폭이 오히려 는다 |
| **카드뮴** | 구멍 차단이 크고 이동은 작다 | 느려져서 얻는 이득과 전류가 줄어 잃는 손실이 **상쇄된다** |
| **온도** | 통로 동역학 전체가 느려진다 | 속도도 진폭도 같이 줄지만 진폭 쪽이 덜 민감하다 |
| **철** | 막이 샌다 | 전류가 축을 따라 가기 전에 **옆으로 새어** 진폭이 속도보다 더 떨어진다 |

**즉 S 는 임의로 만든 지표가 아니라, 기전이 파형에 남긴 자국이다.**

---

## 한계 — 정직하게 ★

### 1. 카드뮴과 온도가 가장 가깝다

S 가 카드뮴 ≈ 0.03–0.08, 온도 ≈ 0.25–0.65 다.
넷 중 **가장 좁은 간격**이고, 잡음이 섞이면 겹칠 수 있다.

→ **온도는 S 로 추론하지 말고 그냥 재라.**
S 는 온도를 **잰 뒤에도 남는** 변화를 설명하는 데 쓴다.

### 2. 온도의 S 가 온도 폭에 따라 변한다

+3 °C 에서 0.264, −3 °C 에서 0.606 으로 **2배 넘게** 움직인다. 상수가 아니다.
**따뜻해지는 쪽과 추워지는 쪽이 비대칭이다** — 부호까지 봐야 한다.

### 3. 진폭은 속도보다 재기 어렵다

전극 접촉 상태 · 체벽 두께 · 전극 간격이 진폭을 직접 흔든다.
**속도는 개체 내 비교로 상쇄되지만 진폭은 덜 상쇄된다.**
실험에서 S 의 변동이 시뮬레이션보다 훨씬 클 것이 거의 확실하다.

→ **단계 1에서 SD_rep 을 잴 때 속도뿐 아니라 진폭의 SD 도 같이 재야 한다.**
이것이 이 모델이 STSY 프로토콜에 요구하는 유일한 변경이다.

### 4. 전부 무수 모델의 값이다

수초를 얹으면 숫자가 바뀔 것이 거의 확실하다.
**갈린다는 구조는 남을 것으로 보지만(우리 판단), 경계값은 다시 뽑아야 한다.**

### 5. 상수가 우리 가정이다

납의 S 가 음수인 것은 `shift_max_mv = 15` 를 넣었기 때문이다.
그 값이 다르면 부호가 바뀔 수 있다
([`금속별_기전.md`](금속별_기전.md)).
**S 의 절대값은 예측이 아니라 「이 가정 하에서의 결과」다.**

## 두 번째 지표 — 시간 경과

S 와 독립적인 판별 축이 하나 더 있다. 농도 2.0 고정
([`../코드/src/sweep.py`](../코드/src/sweep.py) `table_timecourse`):

| 일차 | 납 | 카드뮴 | 철 |
|---|---|---|---|
| 0일 | −10.05 % | −8.76 % | −0.67 % |
| 1일 | −10.05 % | −8.76 % | −7.52 % |
| 2일 | −10.05 % | −8.76 % | −11.68 % |
| 4일 | −10.05 % | −8.76 % | −15.74 % |
| 7일 | −10.05 % | −8.76 % | −17.62 % |

**차단형은 날짜에 평평하고 손상형은 자란다.**
STSY 의 0 · 1 · 2 · 4 · 7일 추적 설계가 이 축을 그대로 잰다.

**두 지표를 같이 쓰면**: S 가 축을 하나, 시간 기울기가 축을 하나 만든다.
두 축의 평면에 찍으면 세 금속이 서로 다른 자리에 온다.

## 파이프라인이 실제로 작동하는가 — 전 구간 검증

시뮬레이션 → 세포외 파형 → 192 kHz 재표본 → 대역통과 → 상호상관 → 속도.
마지막 세 단계는 **저장소에 이미 있는 [`../../분석/src/velocity.py`](../../분석/src/velocity.py)** 다.

| 잡음 | 참값 | 추정값 | 오차 |
|---|---|---|---|
| 없음 | 4.436 m/s | 4.435 m/s | −0.028 % |
| 19.3 µV RMS · 단발 5회 | 4.436 m/s | — | 최대 0.242 % |

(잡음 19.3 µV 는 Yoshida 2009 Fig. 8 실측값 · 원문 확인)

**이것이 `velocity.py` 가 물리로 만든 파형에 대해 검증된 첫 사례다.**
지금까지 그 코드는 가우시안 미분으로 만든 가짜 파형으로만 시험돼 있었다
([`../../분석/README.md`](../../분석/README.md)).

**단, 이 0.24 % 를 SD_rep 예측으로 읽으면 안 된다.** 여기 없는 것이 많다 —
전극 위치 오차(1 mm = 4 %) · 접촉 임피던스 변동 · 60 Hz · 근전위 ·
개체의 자세 변화. 실측 SD_rep 은 이보다 훨씬 나쁠 것이다.

## 발화 확률 — 어디까지 되는가

모델에서 전도가 **완전히 끊기는** 지점이 있다
([`../코드/src/sweep.py`](../코드/src/sweep.py) `table_block`):

| 손상 방식 | 전파하는 한계 | 차단되는 지점 |
|---|---|---|
| Na 전도도 | ×0.50 (3.20 m/s) | **×0.40 부터** |
| 누설 전도도 | ×10 (2.94 m/s) | **×20 부터** |

전이가 **가파르다.** 그 경계 근처에서 막에 잡음을 넣으면
시행마다 성공/실패가 갈리고, 그것이 곧 발화 확률이다.

**그러나 중요한 한계가 하나 있다:**

> **균일하게 오염된 축삭은 차단되지 않는다 — 그냥 느려질 뿐이다.**
> 게이팅 이동을 40 mV 까지 올려도 스파이크는 끝까지 간다.
> 균일한 케이블은 안전계수가 매우 크기 때문이다.

차단이 일어나려면 **손상이 국소적**이어야 한다.
그게 생물학적으로도 더 그럴듯하다 — 손상은 보통 얼룩덜룩하다.

→ 구획마다 다른 파라미터를 주는 기능이 필요하다.
지금 [`../코드/src/axon.py`](../코드/src/axon.py) 는 축삭 전체에 막 파라미터가
하나뿐이라 **아직 못 한다.** 단계 4의 과제다 → [`../로드맵.md`](../로드맵.md).
