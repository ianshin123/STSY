## 갈래 1 — 정상 지렁이의 자극 지속시간–역치 모델

**여러 자극 지속시간에서 역치를 재고, 그 관계에서 rheobase 와 chronaxie 를 추정한다.**
**역치 하나만 비교하지 않는다** — 지속시간을 바꿔가며 재야 r 과 c 가 나온다.

### 수식 (Bähring & Bauer 2014 §APPENDIX · 원문 확인)

**a = 자극 진폭 · t = 자극 지속시간 · r = rheobase · c = chronaxie · q = a × t**

| | 식 | 형태 |
|---|---|---|
| **Lapicque** | **a = r + (r·c)/t** | 쌍곡선. r 은 t → ∞ 의 점근선 |
| **Weiss** | **q = r·(t + c)** | **직선.** 기울기 = r · x절편 = −c |

**chronaxie 는 a = 2r 이 되는 t 다.**

### 지금 있는 재료

| 무엇 | 값 | 어디에 |
|---|---|---|
| **정상 r · c** | r **1.012 ± 0.052 V**(범위 0.4–2.5) · c **0.060 ± 0.005 ms**(범위 0.02–0.3) · n = 64 **시행** | [`Bahring2014`](../%EB%AC%B8%ED%97%8C/Bahring2014_%EB%B9%84%EB%A7%88%EC%B7%A8%EC%B1%94%EB%B2%84.md) Table 1 |
| Weiss 적합값 | r 0.976 ± 0.046 V · c 0.066 ± 0.007 ms | 〃 |
| **적합도** | **Weiss 직선 R² 0.9872 ± 0.0020** 대 쌍곡선 직접 적합 0.9434 ± 0.0077 (n = 64, P < 0.0001) | 〃 |
| 한 실험의 예 | r 1.2 V · c 0.054 ms (Fig. 5A) | 〃 |
| 자극 지속시간 계열 | **1 → 0.5 → 0.2 → 0.1 → 0.08 → 0.06 → 0.04 → 0.02 → 0.01 ms** (9개, 긴 쪽부터) | 〃 §Materials |
| 0.1 ms 에서의 역치 | **1.49 ± 0.08 V** (범위 0.6–4) · n = 74 | 〃 Table 1 |
| **원 데이터 파일** | `threshold_biopac.acq` · `Chronaxie_biopac.acq` — **같은 프로토콜로 저자가 받아 둔 예제 데이터** | [`원문/Bahring2014_보조자료/`](../%EB%AC%B8%ED%97%8C/%EC%9B%90%EB%AC%B8/Bahring2014_%EB%B3%B4%EC%A1%B0%EC%9E%90%EB%A3%8C/) |
| 다른 값 | Kladt 2010 chronaxie **129 µs** · MGF 역치 1.2–2.9 V | [`Kladt2010`](../%EB%AC%B8%ED%97%8C/Kladt2010_%ED%94%84%EB%A1%9C%ED%86%A0%EC%BD%9C9%EC%A2%85.md) |

> ⚠ **전압 기반과 전류 기반은 값이 다르다.** Bähring 은 전압, Kladt 는 전류다.
> Holsheimer 등: **전압 기반 chronaxie 가 전류 기반보다 30–40 % 낮게 나온다.**
> **한 모델 안에서 두 값을 섞지 않는다.**

> **원문이 «theoretically, only two good measurements would be necessary to determine r and c»
> 라고 쓴다.** 측정점을 몇 개 어디에 둘지가 이 갈래에서 다룰 수 있는 문제다.

## 갈래 2 — 농도·노출시간에 따른 전도속도

**「중금속이면 몇 % 느려진다」를 미리 정하지 않는다.**
**농도와 노출시간에 따라 속도가 어떻게 변하는지 모델을 추정한다.**

## 갈래 3 — 시나리오

**근거 없는 수치를 예측하지 않는다.**
**rheobase · chronaxie · 전도속도가 각각 10 · 20 · 30 % 변한다고 두고,
그때 실제 측정 그래프가 어떻게 달라지는지를 본다.**

**실제 실험 뒤에는 이 가상값을 측정값으로 교체해 모델을 보정한다.**

### 시나리오가 그래프에서 어떻게 보이는가

| 무엇이 바뀌면 | 진폭–지속시간 곡선(Lapicque) | Weiss 직선 |
|---|---|---|
| **r 만 바뀐다** | 곡선 전체가 위아래로 · 점근선이 이동 | **기울기가 바뀐다** |
| **c 만 바뀐다** | 곡선의 굽는 자리가 좌우로 | **x절편이 바뀐다** |
| **둘 다** | — | 기울기와 절편이 함께 |

**전도속도는 Δt = Δs / v 이므로 v 가 10 % 느려지면 Δt 가 11.1 % 길어진다.**

## 갈래 4 — 몇 회 반복해야 잡히나

**정상 지렁이의 속도와 측정오차를 가정하고, 중금속 효과가 5 · 10 · 20 · 30 % 일 때
각각 몇 회 반복측정해야 변화가 잡히는지 시뮬레이션한다.**
**「현재 장치와 반복횟수로 어느 정도의 중금속 효과까지 검출 가능한가」**

### 필요한 것 — 측정오차 σ

**보고된 SD 는 전부 개체 간이거나 시행 간이다. 반복측정 SD 는 어느 논문에도 없다** —
목록은 [`../예비실험.md`](../%EC%98%88%EB%B9%84%EC%8B%A4%ED%97%98.md) 4-4-2 절에.

**이번 회차에 같은 자리에서 Δt 를 10회 반복해 잰다**
(2026-09-02 · 신이안) → [`../실험절차.md`](../%EC%8B%A4%ED%97%98%EC%A0%88%EC%B0%A8.md) 5-5.

**그 값이 나오기 전까지 쓸 수 있는 대용값**: O'Gara Fig. 4 대조군의 「초기값 대비 %」
오차막대 ≈ ±4.5 %(SEM, n = 10) → **SD ≈ 14 %**. 군마다 6.6 – 21 %.
**본문에 없고 그림에서 눈으로 읽은 값이며 종도 장치도 다르다.**

### 계산해 둔 것

**대응 설계**(같은 개체를 노출 전후로 비교)를 전제한 값이다.
σ 는 **차이값(또는 비)의 SD** 다 — 한 번 측정의 SD 를 그대로 넣으면 √2 만큼 틀린다
([`../정정기록.md`](../%EC%A0%95%EC%A0%95%EA%B8%B0%EB%A1%9D.md)).

**필요한 개체 수** `n = (2.80·σ/δ)²` (α = 0.05 양측 · 검정력 0.8)

| 잡으려는 효과 δ | σ = 8 % | σ = 15 % | σ = 20 % |
|---|---|---|---|
| 5 % | 20 | 71 | 126 |
| 10 % | 5 | 18 | 31 |
| 20 % | 1.3 | 4.4 | 7.9 |
| 25 % | 0.8 | 2.8 | 5.0 |

**검출 가능한 최소 효과** `δ_min = 2.80·σ/√n`

| n | σ = 8 % | σ = 15 % | σ = 20 % |
|---|---|---|---|
| 5 | 10.0 % | 18.8 % | 25.1 % |
| 10 | 7.1 % | 13.3 % | 17.7 % |
| 20 | 5.0 % | 9.4 % | 12.5 % |
| 30 | 4.1 % | 7.7 % | 10.2 % |

> **이 표는 「이 가정에서의 결과」다.** σ 는 우리 값이 아직 아니다.

### 측정오차가 어디서 오는지 — 계산해 둔 것

**v = Δs / Δt** 이므로 `(σ_v/v)² = (σ_Δs/Δs)² + (σ_Δt/Δt)²`.

**σ_Δt 는 세 항이다**: 샘플 양자화(48 kHz → **1 샘플 = 20.83 µs**) ·
**정점 뭉개짐**(전극 축방향 길이 ÷ 전도속도 — [`../예비실험.md`](../%EC%98%88%EB%B9%84%EC%8B%A4%ED%97%98.md) 에 계산돼 있다) ·
**채널 간 스큐**([`../실험절차.md`](../%EC%8B%A4%ED%97%98%EC%A0%88%EC%B0%A8.md) 4-3 에서 잰다).

**v = 25 m/s · 정점 찍기 ±1 샘플 · 자 ±0.5 mm 로 두었을 때:**

| Δs | Δt | 샘플 수 | 양자화 | 거리 | 합 |
|---|---|---|---|---|---|
| 10 mm | 0.40 ms | 19 | 5.2 % | 5.0 % | 7.2 % |
| 20 mm | 0.80 ms | 38 | 2.6 % | 2.5 % | 3.6 % |
| 30 mm | 1.20 ms | 58 | 1.7 % | 1.7 % | 2.4 % |
| 40 mm | 1.60 ms | 77 | 1.3 % | 1.3 % | 1.8 % |

LGF(v = 7 m/s · Δs = 30 mm)는 Δt 가 206 샘플이라 합이 **1.7 %**.
