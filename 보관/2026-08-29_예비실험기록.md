## 장치

**AD623 없이 TL072 3개로 만든 계측증폭기.** 회로도의 오류를 고쳐가며 완성했다
→ [`../장치/TL072계측증폭기.md`](TL072_%ED%9A%8C%EB%A1%9C%EB%8F%84.md).

**앰프는 작동했다.** 양쪽 전극을 함께 대면 상쇄되어 0 V가 되는 것을 확인했다.

## 1차 — 시침핀 · 마취 · 패러데이 상자

| 항목 | 내용 |
|---|---|
| 마취 | 10 % 에탄올 **4분** |
| 받침 | 코르크판. **자로 간격을 표시**해 위치를 정했다 |
| 전극 | **시침핀 3개**를 몸에 꽂았다 (설계대로) |
| 차폐 | **알루미늄 호일 패러데이 상자** 안에서 진행 |
| 자극 | 물리적으로 치는 자극 |

**결과 — 아무것도 잡히지 않았다.** 화면은 평형이었고, 어떤 식으로 쳐도 변화가 없었다.

**전극 하나만 꽂혀 있을 때는 신호가 잡혔다** → 연결 오류가 아니다.

### 지렁이 #1 의 상태 (실험 후)

- **입에서 계속 무언가를 토하며 뱉어냈다**
- **머리 부분에 물을 뿌렸을 때 말고는 움직이지 않았다**

## 2차 — 악어클립 + 커터 칼날 · 핀 없음

스코프 설정을 바꾸고(**Auto → Normal**) 다시 했다.

| 항목 | 내용 |
|---|---|
| 마취 | 10 % 에탄올 **5분** |
| 전극 | **시침핀 없음.** 악어클립에 **커터 칼날**을 물려 **접촉 면적을 늘렸다** |
| 차폐 | **패러데이 상자를 쓰지 않았다** |

### 관찰된 것

- **미세한 신호도 아주 잘 잡혔다** (1차의 시침핀보다 뚜렷)
- **마취하지 않은 지렁이**를 그냥 붙들어 두고 전극을 대고 손으로 툭툭 쳤을 때
  **오실로스코프가 분명히 변하는 것이 보였다**
- 지렁이 #2 의 평형 상태가 **고정된 물결 모양**이었다
- **마취한 뒤 핀 없이 눕혀 전극을 대니 자극이 잡히지 않았다**
- **패러데이 상자는 1차·2차 모두 우리 실험실에서는 영향이 별로 없었다**

### 구속 방식 — 관에서 클립으로

**관에 넣어 보았으나** 여유 공간이 조금 있으면 **지렁이가 몸을 비틀어 뒤로 빠져나가려 했다.**

그래서 바꾼 방식: **악어클립에 커터 칼날을 물리고, 그 상태를 마스킹테이프로 코르크판에 붙여
악어클립(전극)과 코르크판 사이에 지렁이를 끼웠다.**

### 지렁이 #2 의 상태 (실험 후)

- **마취가 풀린 뒤에도 움직이지 못했다.** 살아 있기는 하다
- 먹이를 주고 회복되는지 지켜보는 중
