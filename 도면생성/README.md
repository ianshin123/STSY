# 도면 생성 스크립트

지금 쓰는 **AD623 2채널 판**의 도면을 만드는 코드다.
**도면을 고칠 때는 PNG를 직접 편집하지 말고 여기 스크립트를 고친 뒤 다시 돌린다.**

> ### ⚠ 이것은 「그리는 코드」다
>
> [`CLAUDE.md`](../CLAUDE.md) 는 이 저장소에 분석·시뮬레이션 코드를 두지 않는다.
> **여기 있는 것은 도면을 그리는 코드일 뿐 어떤 수치도 만들어내지 않는다.**
> 도면에 적히는 값은 전부 [`기록.md`](../%EA%B8%B0%EB%A1%9D.md) 「부품값을 정하는 식」에서
> 사람이 정한 것을 옮긴 것이다.

## ★ 결선의 정본은 `보드자료_AD623.py` 한 파일이다

**배치도 두 장과 전체 연결도가 같은 파일을 읽는다.** 예전에는 브레드보드 그림이 스크립트마다
따로 있어 한쪽만 고치면 어긋났다 — 그 중복을 없앴다.
**결선·부품값·번호를 고칠 때는 이 파일 하나만 고치고 아래를 순서대로 다시 돌린다.**

| 스크립트 | 만드는 것 |
|---|---|
| **`보드자료_AD623.py`** | **그림을 안 만든다.** 1번·2번 보드의 결선 · 부품값 · 번호 · 좌표계 · 색 |
| **`검증_AD623.py`** | **그림을 안 만든다.** 위 배치가 물리·전기적으로 말이 되는지 검사한다 — **고쳤으면 이것부터 돌린다** |
| `브레드보드_배치도_2채널.py` | `장치/그림/브레드보드_배치도_{1,2}번보드.svg` · `.png` |
| `전체연결도_2채널.py` | `장치/그림/전체연결도_2채널.svg` · `.png` 와 `장치/전체연결도_2채널.pdf` |
| `기호표.py` | `장치/그림/기호표.svg` · `.png` |

```sh
cd 도면생성
python3 검증_AD623.py              # ★ 먼저. 아무 ✗ 도 안 나와야 한다
python3 기호표.py
python3 브레드보드_배치도_2채널.py   # 배치도 두 장
python3 전체연결도_2채널.py         # 전체 연결도 + 1쪽 PDF
```

## `검증_AD623.py` 가 보는 것

`보드자료_AD623.py` 를 직접 읽어 아래를 검사한다. 정상이면 검사 결과와 필터 계산값을 찍고 0으로 끝난다.

| 검사 | 왜 |
|---|---|
| **한 구멍에 둘이 들어가나** | 결선표 21번과 22번이 같은 구멍 `(10,G)` 를 쓰고 있던 사고가 있었다 |
| **레일에 구멍이 없는 자리인가** | **레일 구멍은 5개마다 한 칸씩 비어 있다** — `5·11·17·23·29` 열 (`RAILGAP=5`) |
| **소자가 남의 맨 리드 위를 지나가나** | 「구멍 중복 없음」은 도면 위에서 안 겹친다는 뜻이지 실물에서 안 닿는다는 뜻이 아니다. 저항은 두 구멍 사이에 **누워서** 그 사이 열 위를 지나간다 |
| **AD623 모듈 바닥 면적과 겹치나** | 모듈 기판이 핀 배열보다 크다 |
| **전원·신호 결선의 전기적 일관성** | OUT/IN+/IN− 가 단락되지 않았나 · 필터가 제 노드에 붙었나 |
| **필터 값** | 고역·저역 차단과 60 Hz 통과율을 실제 부품값에서 계산해 찍는다 |

**점퍼선 위는 무해하다** — 금속 핀이 플라스틱 몸체 안에 들어 있다.
**맨 리드(저항·커패시터) 위가 문제다.** 걸리면 **둘 중 하나를 같은 열의 다른 행으로 옮긴다** —
같은 열이면 노드가 같아 회로는 안 바뀐다.

> **여유가 얼마나 되는지도 봐라.** 1/4 W 금속피막 저항의 몸통은 **6.3 mm**,
> 세라믹 커패시터는 **4 mm** 쯤이다. 구멍 간격이 2.54 mm 이므로
> **4열(10.2 mm) 건너뛰면 몸통이 간신히 덮고, 5열 이상이면 맨 리드가 드러난다.**

> **레일은 통째로 한 덩어리라** 구멍이 어긋나도 옆 구멍에 꽂으면 전기적으로 같다.
> 그래도 도면은 맞춰 둔다 — 조립하는 사람이 그림과 실물이 다르면 멈추게 된다.

## 도면 스크립트가 그리는 방식

세 스크립트 모두 **문자열로 SVG 를 직접 쌓아 올린 뒤 `cairosvg` 로 PNG 를 뽑는다.**
`o=[]; a=o.append` 로 SVG 조각을 모으고 마지막에 `'\n'.join(o)` 한다.

### 브레드보드 좌표계

**구멍 한 칸 = 2.54 mm = `P` 픽셀(32).** 실물 치수를 그대로 화면에 옮긴다.

```python
cx(c)   # 열 번호 c 의 x 좌표
Y(r)    # 행 이름 r 의 y 좌표. 'A'–'J' 는 터미널, 'TV','TG','BG','BV' 는 레일
```

그래서 결선표의 `(5, B)` 는 코드에서 `wire((5,'B'), ...)` 로 그대로 쓴다.

| 함수 | 하는 일 |
|---|---|
| `wire(p1,p2,색)` | 수–수 점퍼선. 양끝에 점을 찍는다 |
| `part(p1,p2,이름,몸통색,폭,lp)` | 저항·커패시터. `lp` 는 이름표 좌표 |
| `wirepath(경로,색,두께)` | 보드 바깥 배선. **흰 테두리를 먼저 깔아** 교차점에서 위/아래가 보이게 한다 |
| `R([점,점,…],반경)` | 모서리를 둥글린 꺾은선 경로 |
| `post(x,y,색,번호)` | 시침핀 기둥 자리에 번호 붙은 동그라미 |
| `female/male/gator(x,y,회전,색)` | 암 커넥터 · 수 커넥터 · 악어클립 그림 |
| `T(x,y,글,크기,색,굵기,정렬)` | 글자 |
| `panel(x,y,w,h,제목)` | 테두리 있는 구역 |

### 색 — 실물의 종류를 나타낸다. 역할이 아니다

```python
JMP='#1a5fb4'   # 수–수 점퍼선
ALG='#0f9b8e'   # 악어클립 테스트 리드선
SNP='#8e44ad'   # 건전지 스냅 연선
GRY='#9a9a9a'   # 부품 다리 · 시침핀
ORG='#c0392b'   # 경고
RAILR='#e2a8a8'; RAILB='#aab8dd'   # 보드에 인쇄된 레일 줄 (전선이 아니다)
```

`보드자료_AD623.py` 위쪽에 이 상수들이 모여 있다. 색을 다시 나누려면 그 줄만 고치면 된다.

### AD623 모듈 바닥 면적

모듈 기판이 핀 배열보다 크다는 것을 주황 점선 사각형으로 그린다.
`MOX0,MOX1,MOY0,MOY1` 이 그 범위이고, 큰 고정 구멍 2개는 2열 E·F행에 이중 원으로 그린다.
**실물 치수를 아직 재지 않았으므로 넉넉히 잡은 값이다.** 재고 나면 이 네 숫자를 고친다.
