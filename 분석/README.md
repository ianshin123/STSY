## 모듈

### `src/power.py`

대응표본 t-검정의 검출력. **비중심 t 분포로 정확히** 계산한다.

| 함수 | 하는 일 |
|---|---|
| `power_paired(n, d)` | Cohen's d 에서 검정력 |
| `mde(n, sd_pct)` | 검출 가능 최소 변화율 (%) |
| `required_n(sd_pct, target_pct)` | 목표 검출에 필요한 개체 수 |
| `mde_normal_approx(...)` | 정규근사. **비교용. 설계에 쓰지 마라** |
| `table()` | 정리/통계_검출력.md 의 표를 재생성 |

문서의 표는 이 코드로 만든 것이므로, 표를 고칠 일이 생기면
**코드를 고치고 다시 뽑아서** 문서에 넣는다.

일부러 넘기려면 `git commit --no-verify`.

### `src/velocity.py`

두 채널의 Δt → 전도속도.

| 함수 | 하는 일 |
|---|---|
| `bandpass(x, fs)` | 영위상 대역통과 (300–3000 Hz). **filtfilt를 쓴다** — 인과 필터는 채널마다 지연을 넣는데 우리가 재는 게 바로 그 지연이다 |
| `estimate_dt(a, b, fs, lag_offset_s)` | 상호상관 + 포물선 보간. `lag_offset_s`에 캘리브레이션으로 잰 **채널 간 고정 지연**을 넣는다 |
| `velocity(d_mm, dt_s)` | v = d / Δt |
| `classify(v)` | 속도로 MGF / LGF 판별 |
| `velocity_uncertainty(...)` | 오차 전파 |

## 검증에서 나온 수치 ★

합성 파형(이상성 파형 + 잡음이 정점의 30 %, 192 kHz, d = 25 mm)에서 잰 Δt 추정 오차:

| 조건 | RMS 오차 |
|---|---|
| **단발 1회** | **12.3 µs** |
| 50회 평균화 | **0.55 µs** |
| (참고) 목표 효과 3 % = | **25.8 µs** |

**단발 추정은 목표 효과 대비 여유가 2배밖에 없다.**
50회 평균화를 하면 47배가 된다.

**이것이 평균화를 선택이 아니라 필수로 만드는 정량적 근거다.**
단계 0은 평균화를 하지 않지만, 단계 0의 목표는 "15–45 m/s 범위에 드는가"이지
3 % 판별이 아니다.

`tests/test_velocity.py::test_평균화가_필요한_이유` 가 이 수치를 지킨다.

**한계**: 이건 합성 파형 시험이다.
실제 잡음은 백색이 아니고(60 Hz 하모닉 · 근전위 · 전극 표류),
두 채널의 파형 모양이 전파 도중 달라질 수 있다.
**실측 SD_rep은 단계 1에서 직접 재야 하고, 이 값보다 나쁠 것이 거의 확실하다.**

## 거리 오차가 지배한다

d = 25 mm에서 오차 전파:

| 오차원 | 크기 | v에 주는 상대오차 |
|---|---|---|
| 전극 간격 σ_d = 1 mm | — | **4.0 %** |
| Δt 1샘플 (192 kHz) | 5.2 µs | 0.6 % |

**전극 간격을 자로 정확히 재는 것이 샘플레이트를 올리는 것보다 6배 중요하다.**
장비를 더 비싸게 사는 것으로는 해결되지 않는 종류의 문제다.
